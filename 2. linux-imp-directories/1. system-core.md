# System Core Directories

Essential directories required for the system to boot and function at a basic level.

---

## / (Root)

The root directory is the top of the filesystem hierarchy. Everything in Linux is located under `/`.

### Key Points

- Only one root directory exists per system
- Represented by a single forward slash `/`
- All other directories branch from here
- Should be kept small (essential files only)
- Cannot be deleted or renamed

### What Belongs Here

```
/
├── bin/
├── boot/
├── dev/
├── etc/
├── home/
├── ...
└── (other top-level directories)
```

Only directories and a few special files should be in `/`:

```bash
$ ls -la /
total 68
drwxr-xr-x  19 root root  4096 Jan 15 10:00 .
drwxr-xr-x  19 root root  4096 Jan 15 10:00 ..
drwxr-xr-x   2 root root  4096 Jan 10 12:00 bin
drwxr-xr-x   3 root root  4096 Jan 10 12:00 boot
drwxr-xr-x  18 root root  3840 Feb 14 08:00 dev
drwxr-xr-x  85 root root  4096 Feb 14 09:00 etc
drwxr-xr-x   3 root root  4096 Jan 05 14:00 home
...
```

## /bin (Essential Binaries)

Contains essential command binaries needed for **single-user mode** and for **all users**.

### Key Points

- Commands needed before other filesystems are mounted
- Available to all users
- Must not have subdirectories
- On modern systems: often symlinked to `/usr/bin`

### Common Commands Found Here

| Command | Purpose |
|---------|---------|
| `ls` | List directory contents |
| `cp` | Copy files |
| `mv` | Move/rename files |
| `rm` | Remove files |
| `cat` | Concatenate files |
| `echo` | Print text |
| `bash` | Bourne Again Shell |
| `sh` | Shell |
| `chmod` | Change permissions |
| `chown` | Change ownership |
| `mkdir` | Make directories |
| `pwd` | Print working directory |
| `date` | Show date/time |
| `df` | Disk free space |
| `mount` | Mount filesystems |
| `grep` | Search text patterns |

### Example

```bash
$ ls /bin | head -20
bash
cat
chmod
chown
cp
date
dd
df
dir
echo
...

# Check if /bin is a symlink (modern systems)
$ ls -la /bin
lrwxrwxrwx 1 root root 7 Jan 1 00:00 /bin -> usr/bin
```

## /sbin (System Binaries)

Contains essential binaries for **system administration**. Typically requires root privileges.

### Key Points

- System maintenance and administrative commands
- Usually requires root/sudo to run
- Needed for booting and system repair
- On modern systems: often symlinked to `/usr/sbin`

### Common Commands Found Here

| Command | Purpose |
|---------|---------|
| `init` | System initialization |
| `shutdown` | Shutdown system |
| `reboot` | Reboot system |
| `fsck` | Filesystem check/repair |
| `fdisk` | Partition table editor |
| `mkfs` | Make filesystem |
| `mount` | Mount filesystem |
| `ifconfig` | Network interface config (legacy) |
| `ip` | Network configuration |
| `iptables` | Firewall rules |
| `route` | Routing table |
| `modprobe` | Load kernel modules |
| `lsmod` | List kernel modules |
| `systemctl` | systemd control |

### Example

```bash
$ ls /sbin | head -15
agetty
badblocks
blkid
blockdev
cfdisk
debugfs
e2fsck
fdisk
fsck
...

# Many require root
$ fdisk -l
fdisk: cannot open /dev/sda: Permission denied

$ sudo fdisk -l
Disk /dev/sda: 500 GiB...
```

### /bin vs /sbin

| Aspect | `/bin` | `/sbin` |
|--------|--------|---------|
| Users | All users | Primarily root |
| Purpose | Basic commands | System administration |
| Examples | `ls`, `cp`, `cat` | `fdisk`, `fsck`, `init` |

## /boot (Boot Loader)

Contains files needed to **boot the system**: kernel, initrd, and bootloader.

### Key Points

- Required for system startup
- Contains the Linux kernel
- Contains initial RAM disk (initrd/initramfs)
- Contains bootloader configuration (GRUB)
- Often a separate partition (especially with UEFI)

### Typical Contents

```
/boot/
├── config-5.15.0-generic       # Kernel build configuration
├── grub/                        # GRUB bootloader
│   ├── grub.cfg                 # GRUB configuration
│   └── fonts/
├── initrd.img-5.15.0-generic   # Initial RAM disk
├── System.map-5.15.0-generic   # Kernel symbol map
├── vmlinuz-5.15.0-generic      # Linux kernel (compressed)
└── efi/                         # EFI boot files (UEFI systems)
```

### Key Files Explained

| File | Purpose |
|------|---------|
| `vmlinuz-*` | Compressed Linux kernel |
| `initrd.img-*` / `initramfs-*` | Initial RAM disk with drivers |
| `config-*` | Kernel build configuration |
| `System.map-*` | Kernel symbol table (debugging) |
| `grub/grub.cfg` | GRUB bootloader config |

### Example

```bash
$ ls -lh /boot
-rw-r--r-- 1 root root 256K Jan 10 config-5.15.0-generic
drwxr-xr-x 5 root root 4.0K Jan 10 grub
-rw-r--r-- 1 root root  89M Jan 10 initrd.img-5.15.0-generic
-rw------- 1 root root 6.4M Jan 10 System.map-5.15.0-generic
-rw------- 1 root root  11M Jan 10 vmlinuz-5.15.0-generic

# View GRUB config (don't edit directly!)
$ cat /boot/grub/grub.cfg | head -20
```

### Warning

> Never delete files from `/boot` unless you know exactly what you're doing. Deleting the kernel or initrd will make your system unbootable!

## /lib (Libraries)

Contains shared libraries needed by programs in `/bin` and `/sbin`.

### Key Points

- Essential shared libraries (`.so` files)
- Kernel modules in `/lib/modules`
- On modern systems: often symlinked to `/usr/lib`
- 64-bit systems may have `/lib64` as well

### Structure

```
/lib/
├── firmware/           # Hardware firmware files
├── modules/            # Kernel modules
│   └── 5.15.0-generic/
│       ├── kernel/
│       └── modules.dep
├── systemd/            # systemd components
├── x86_64-linux-gnu/   # Architecture-specific libs
└── *.so*               # Shared libraries
```

### Key Subdirectories

| Directory | Contents |
|-----------|----------|
| `/lib/modules/` | Kernel modules (.ko files) |
| `/lib/firmware/` | Device firmware |
| `/lib/systemd/` | systemd unit files |

### Example

```bash
# View libraries
$ ls /lib/*.so* | head -5
/lib/ld-linux-x86-64.so.2
/lib/libc.so.6
/lib/libm.so.6
...

# View kernel modules
$ ls /lib/modules/
5.15.0-generic

$ ls /lib/modules/$(uname -r)/kernel/
arch  crypto  drivers  fs  net  sound  ...

# Check library dependencies of a program
$ ldd /bin/ls
    linux-vdso.so.1
    libselinux.so.1 => /lib/x86_64-linux-gnu/libselinux.so.1
    libc.so.6 => /lib/x86_64-linux-gnu/libc.so.6
    ...
```

## /etc (Configuration)

Contains **all system-wide configuration files**. This is where you customize system behavior.

### Key Points

- System configuration files (text files)
- No binary executables (except legacy scripts)
- "etc" historically meant "et cetera"
- Host-specific configuration

### Important Files

| File | Purpose |
|------|---------|
| `/etc/passwd` | User account information |
| `/etc/shadow` | Encrypted passwords |
| `/etc/group` | Group definitions |
| `/etc/fstab` | Filesystem mount table |
| `/etc/hosts` | Static hostname to IP mapping |
| `/etc/hostname` | System hostname |
| `/etc/resolv.conf` | DNS configuration |
| `/etc/sudoers` | Sudo permissions |
| `/etc/crontab` | System cron jobs |
| `/etc/environment` | System-wide environment |
| `/etc/profile` | System-wide shell profile |
| `/etc/ssh/` | SSH configuration |

### Important Subdirectories

| Directory | Purpose |
|-----------|---------|
| `/etc/apt/` | APT package manager config |
| `/etc/nginx/` | Nginx web server config |
| `/etc/systemd/` | systemd configuration |
| `/etc/cron.d/` | Cron job definitions |
| `/etc/default/` | Default configs for services |
| `/etc/init.d/` | Legacy init scripts |
| `/etc/network/` | Network configuration |
| `/etc/ssl/` | SSL certificates |

### Example

```bash
# View password file
$ cat /etc/passwd | head -5
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
...

# View filesystem mount table
$ cat /etc/fstab
# <file system>  <mount point>  <type>  <options>  <dump>  <pass>
UUID=xxx         /              ext4    defaults   0       1
UUID=yyy         /boot          ext4    defaults   0       2

# View hosts file
$ cat /etc/hosts
127.0.0.1       localhost
127.0.1.1       myhostname

# Check hostname
$ cat /etc/hostname
myhostname
```

### Common Tasks

```bash
# Edit hosts file
$ sudo nano /etc/hosts

# Edit sudoers (use visudo!)
$ sudo visudo

# Add a cron job
$ sudo nano /etc/crontab

# Edit network config
$ sudo nano /etc/network/interfaces    # Debian
$ sudo nano /etc/netplan/              # Ubuntu with netplan
```

---

> **Pro Tip:** Always back up `/etc` before making changes: `sudo cp /etc/somefile /etc/somefile.bak`
