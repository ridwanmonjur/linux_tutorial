# Mount Points & Optional Software

Directories for mounting external filesystems and installing optional/third-party software.

---

## /mnt (Temporary Mount Point)

A generic mount point for **temporarily mounting filesystems** manually.

### Key Points

- For manual, temporary mounts
- System administrator use
- Empty by default
- Use for one-time mounts, not permanent

### Example Uses

```bash
# Mount a partition temporarily
$ sudo mount /dev/sdb1 /mnt
$ ls /mnt
files  documents  photos

# Mount an ISO file
$ sudo mount -o loop disk.iso /mnt

# Mount a network share
$ sudo mount -t nfs server:/share /mnt
$ sudo mount -t cifs //server/share /mnt -o user=admin

# Mount with specific filesystem
$ sudo mount -t ext4 /dev/sdc1 /mnt

# Unmount when done
$ sudo umount /mnt
```

### Creating Subdirectories

For multiple temporary mounts:

```bash
$ sudo mkdir /mnt/usb
$ sudo mkdir /mnt/backup
$ sudo mkdir /mnt/network

$ sudo mount /dev/sdc1 /mnt/usb
$ sudo mount //server/backup /mnt/network
```

### /mnt vs /media

| Aspect | `/mnt` | `/media` |
|--------|--------|----------|
| Use | Manual mounts | Automatic mounts |
| Who mounts | Administrator | System (udev/udisks) |
| Typical use | Temporary, one-time | Removable media |
| Examples | Recovery, maintenance | USB drives, CDs |

## /media (Removable Media)

Mount point for **removable media** like USB drives, CDs, and DVDs. Managed automatically by the system.

### Key Points

- Auto-mounted removable devices
- Managed by udisks/udev
- User-accessible without root
- Subdirectories created per-device

### Structure

```
/media/
└── username/
    ├── USB_DRIVE/          # USB drive (by label)
    ├── CDROM/              # CD/DVD
    ├── 8GB_Flash/          # Another USB
    └── 3A4F-2B1C/          # Drive without label (by UUID)
```

### Example

```bash
# List mounted media
$ ls /media/$USER
USB_DRIVE  BACKUP_DISK

# View contents of USB drive
$ ls /media/$USER/USB_DRIVE
documents  photos  videos

# Check mount details
$ mount | grep /media
/dev/sdc1 on /media/john/USB_DRIVE type vfat (rw,nosuid,nodev,...)

# Safely eject
$ udisksctl unmount -b /dev/sdc1
$ udisksctl power-off -b /dev/sdc
```

### Manual Control

```bash
# Mount using udisks (user-level, no sudo)
$ udisksctl mount -b /dev/sdc1
Mounted /dev/sdc1 at /media/john/USB_DRIVE

# Unmount
$ udisksctl unmount -b /dev/sdc1

# Using command line
$ gio mount -d /dev/sdc1
$ gio mount -u /media/john/USB_DRIVE
```

### Permissions

```bash
# Media is typically mounted with user permissions
$ ls -la /media/john/
drwxr-x---+ 3 root root 4096 Feb 14 10:00 .
drwxr-xr-x  3 root root 4096 Feb 14 10:00 ..
drwxr-xr-x  5 john john 4096 Feb 14 10:00 USB_DRIVE
```

## /opt (Optional Software)

For **optional, add-on software packages**—typically third-party or commercial software that's self-contained.

### Key Points

- Third-party software
- Self-contained packages
- Each package in its own subdirectory
- Not managed by system package manager
- Similar concept to `/Applications` on macOS

### Structure

```
/opt/
├── google/
│   └── chrome/
├── microsoft/
│   └── powershell/
├── slack/
├── zoom/
├── android-studio/
├── jetbrains/
│   ├── idea/
│   └── pycharm/
└── lampp/              # XAMPP
```

### Typical Layout Per Application

```
/opt/myapp/
├── bin/                # Executables
├── lib/                # Libraries
├── share/              # Shared data
├── etc/                # Configuration (or in /etc/opt/myapp)
└── var/                # Variable data (or in /var/opt/myapp)
```

### Example

```bash
# View installed optional software
$ ls /opt
google  android-studio  zoom

# Run application
$ /opt/google/chrome/google-chrome

# Add to PATH (in ~/.bashrc)
export PATH="$PATH:/opt/android-studio/bin"

# Install something to /opt manually
$ sudo mkdir /opt/myapp
$ sudo tar -xzf myapp.tar.gz -C /opt/myapp

# Or with symlinks
$ sudo ln -s /opt/myapp/bin/myapp /usr/local/bin/myapp
```

### Configuration and Data

Related directories:
- `/etc/opt/` - Configuration for `/opt` software
- `/var/opt/` - Variable data for `/opt` software

```bash
/etc/opt/
└── myapp/
    └── config.ini

/var/opt/
└── myapp/
    ├── logs/
    └── data/
```

### /opt vs /usr/local

| Aspect | `/opt` | `/usr/local` |
|--------|--------|--------------|
| Structure | Self-contained subdirs | Mirrors `/usr` (bin, lib, share) |
| Package style | Monolithic | Traditional Unix |
| Uninstall | Delete directory | Remove individual files |
| Examples | Chrome, Zoom, Android Studio | Manually compiled software |

## /usr (User Programs)

The largest directory—contains the majority of user programs, libraries, and documentation. Originally meant "user" but now contains shareable, read-only data.

### Key Points

- Most installed software lives here
- Read-only (could be mounted read-only)
- Shareable across systems
- Mirrors root structure (has its own bin, lib, etc.)
- On modern systems: `/bin`, `/lib` symlink here

### Structure

```
/usr/
├── bin/            # User commands (most commands)
├── sbin/           # Non-essential system commands
├── lib/            # Libraries for /usr/bin and /usr/sbin
├── lib64/          # 64-bit libraries
├── include/        # C header files
├── share/          # Architecture-independent data
│   ├── doc/        # Documentation
│   ├── man/        # Man pages
│   ├── icons/      # Icon themes
│   ├── applications/  # .desktop files
│   └── locale/     # Translations
├── local/          # Locally installed software
├── src/            # Source code (kernel headers)
└── games/          # Game executables
```

### Key Subdirectories

#### /usr/bin (User Binaries)

```bash
# Most commands are here
$ ls /usr/bin | wc -l
2500

# Examples
$ which python3
/usr/bin/python3

$ which vim
/usr/bin/vim

$ which git
/usr/bin/git
```

#### /usr/sbin (System Binaries)

```bash
# System administration commands
$ ls /usr/sbin | head
adduser
cron
useradd
visudo
...
```

#### /usr/lib (Libraries)

```bash
# Shared libraries
$ ls /usr/lib/x86_64-linux-gnu/*.so | head
/usr/lib/x86_64-linux-gnu/libc.so
/usr/lib/x86_64-linux-gnu/libpthread.so
...

# systemd units
$ ls /usr/lib/systemd/system/ | head
```

#### /usr/share (Shared Data)

```bash
# Documentation
$ ls /usr/share/doc | head

# Man pages
$ ls /usr/share/man
man1  man2  man3  man4  man5  man6  man7  man8

# Icons
$ ls /usr/share/icons
hicolor  Adwaita  ...

# Desktop entries
$ ls /usr/share/applications | head
firefox.desktop
code.desktop
...
```

#### /usr/include (Header Files)

```bash
# C/C++ headers for development
$ ls /usr/include
stdio.h  stdlib.h  linux/  sys/  ...

# Used when compiling
#include <stdio.h>
```

### /usr/local (Locally Installed)

For software installed locally (not from package manager). Mirrors `/usr` structure:

```
/usr/local/
├── bin/            # Local executables
├── sbin/           # Local system executables
├── lib/            # Local libraries
├── include/        # Local headers
├── share/          # Local shared data
│   └── man/        # Local man pages
└── src/            # Local source
```

```bash
# Typical manually compiled installation
$ ./configure --prefix=/usr/local
$ make
$ sudo make install
# Installs to /usr/local/bin, /usr/local/lib, etc.

# Add to PATH (usually already included)
export PATH="/usr/local/bin:$PATH"

# View locally installed
$ ls /usr/local/bin
myprogram  custom-tool
```

### Modern Symlinks

On many modern systems (Fedora, Arch, Ubuntu 20.04+):

```bash
$ ls -la /bin
lrwxrwxrwx 1 root root 7 Jan 1 00:00 /bin -> usr/bin

$ ls -la /sbin
lrwxrwxrwx 1 root root 8 Jan 1 00:00 /sbin -> usr/sbin

$ ls -la /lib
lrwxrwxrwx 1 root root 7 Jan 1 00:00 /lib -> usr/lib
```

This "merged /usr" simplifies the filesystem while maintaining compatibility.

## Summary Table

| Directory | Purpose | Managed By |
|-----------|---------|------------|
| `/mnt` | Temporary manual mounts | Admin (manual) |
| `/media` | Removable media | System (udisks) |
| `/opt` | Optional third-party software | Admin/Installer |
| `/usr` | Most system programs | Package manager |
| `/usr/local` | Locally compiled software | Admin (make install) |

## Mounting Cheat Sheet

```bash
# View all mounts
$ mount
$ df -h

# Mount filesystem
$ sudo mount /dev/sdX1 /mnt

# Mount with options
$ sudo mount -o ro /dev/sdX1 /mnt           # Read-only
$ sudo mount -o loop image.iso /mnt          # ISO file
$ sudo mount -t ntfs /dev/sdX1 /mnt          # NTFS

# Unmount
$ sudo umount /mnt
$ sudo umount /dev/sdX1

# Force unmount (busy filesystem)
$ sudo umount -l /mnt      # Lazy unmount
$ sudo umount -f /mnt      # Force

# Find what's using mount point
$ lsof +f -- /mnt
$ fuser -vm /mnt

# Permanent mounts: add to /etc/fstab
$ sudo nano /etc/fstab
/dev/sdb1  /data  ext4  defaults  0  2
```

---

> **Pro Tip:** Use `mount | column -t` for a cleaner view of mounted filesystems.
