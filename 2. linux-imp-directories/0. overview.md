# Important Linux Directories

A guide to understanding the Linux filesystem hierarchy. All directories branch from `/` (root), and each has a specific purpose defined by the Filesystem Hierarchy Standard (FHS).

---

## Visual Overview

```
/                       # Root - everything starts here
├── bin/                # Essential user commands
├── sbin/               # Essential system/admin commands
├── boot/               # Boot loader files, kernel
├── dev/                # Device files
├── etc/                # System configuration files
├── home/               # User home directories
├── lib/                # Essential shared libraries
├── media/              # Removable media mount points
├── mnt/                # Temporary mount points
├── opt/                # Optional/third-party software
├── proc/               # Process & kernel info (virtual)
├── root/               # Root user's home directory
├── run/                # Runtime variable data
├── srv/                # Service data (web, FTP)
├── sys/                # Kernel & device info (virtual)
├── tmp/                # Temporary files
├── usr/                # User programs & data (read-only)
└── var/                # Variable data (logs, mail, spool)
```

---

## Quick Reference Table

| Directory | Purpose | Examples |
|-----------|---------|----------|
| `/` | Root filesystem | Everything branches from here |
| `/bin` | Essential binaries | `ls`, `cp`, `cat`, `bash` |
| `/sbin` | System binaries | `fdisk`, `fsck`, `init`, `reboot` |
| `/boot` | Boot files | `vmlinuz`, `initrd`, GRUB |
| `/dev` | Device files | `sda`, `tty`, `null`, `random` |
| `/etc` | Configuration | `passwd`, `fstab`, `hosts` |
| `/home` | User directories | `/home/john`, `/home/jane` |
| `/lib` | Shared libraries | `.so` files for `/bin`, `/sbin` |
| `/media` | Removable media | USB drives, CDs |
| `/mnt` | Temporary mounts | Manual mount point |
| `/opt` | Optional software | Third-party apps |
| `/proc` | Process info | PID folders, `cpuinfo` |
| `/root` | Root's home | Admin user home |
| `/run` | Runtime data | PID files, sockets |
| `/srv` | Service data | Web/FTP server files |
| `/sys` | System/device info | Hardware attributes |
| `/tmp` | Temporary files | Cleared on reboot |
| `/usr` | User programs | Most installed software |
| `/var` | Variable data | Logs, databases, mail |

## Key Concepts

### Read-Only vs Writable

| Type | Directories | Notes |
|------|-------------|-------|
| **Read-only** | `/bin`, `/sbin`, `/lib`, `/usr`, `/boot` | Can be mounted read-only |
| **Writable** | `/home`, `/var`, `/tmp`, `/run` | Need write access |

### Static vs Variable

| Type | Directories | Notes |
|------|-------------|-------|
| **Static** | `/bin`, `/sbin`, `/lib`, `/usr`, `/opt` | Don't change without admin action |
| **Variable** | `/var`, `/tmp`, `/run`, `/home` | Change during normal operation |

### Real vs Virtual

| Type | Directories | Notes |
|------|-------------|-------|
| **Real** | Most directories | Actual files on disk |
| **Virtual** | `/proc`, `/sys`, `/dev`, `/run` | Generated by kernel, exist in RAM |

## Modern Changes (systemd era)

Many modern distributions have merged some directories:

```
/bin  → /usr/bin   (symlink)
/sbin → /usr/sbin  (symlink)
/lib  → /usr/lib   (symlink)
```

This simplifies the filesystem while maintaining compatibility.

## Exploring Commands

```bash
# View root directory
ls -la /

# Check disk usage by directory
du -sh /*

# Find which filesystem a directory is on
df -h /home

# See directory tree
tree -L 1 /

# Check if directory is a symlink
ls -la /bin
# lrwxrwxrwx 1 root root 7 /bin -> usr/bin
```
