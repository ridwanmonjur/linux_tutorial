# more & less - File Pagers

`more` and `less` are pager programs used to view file contents one screen at a time. Unlike `cat`, which dumps everything at once, pagers let you scroll through large files interactively.

**Remember:** "less is more" - `less` has more features than `more`.

---

## Quick Comparison

| Feature | `more` | `less` |
|---------|--------|--------|
| Scroll forward | Yes | Yes |
| Scroll backward | Limited | Yes |
| Search forward | Yes | Yes |
| Search backward | No | Yes |
| Horizontal scroll | No | Yes |
| View multiple files | Basic | Advanced |
| Edit file | No | Yes (v key) |
| Mark positions | No | Yes |
| Filter output | No | Yes |

---

# more

The original Unix pager. Simple but limited - primarily scrolls forward only.

## Basic Usage

```bash
# View a file
more filename.txt

# View multiple files
more file1.txt file2.txt

# Pipe command output
ls -la | more
cat largefile.txt | more
```

## Common Flags

| Flag | Description |
|------|-------------|
| `-d` | Display help prompts ("Press space to continue") |
| `-f` | Count logical lines (useful for long lines) |
| `-l` | Ignore form feed (^L) characters |
| `-p` | Clear screen before displaying |
| `-c` | Paint screen from top (no scrolling) |
| `-s` | Squeeze multiple blank lines into one |
| `-u` | Suppress underlining |
| `+n` | Start at line number n |
| `+/pattern` | Start at first match of pattern |
| `-n` | Set screen size to n lines |

## Navigation Keys

| Key | Action |
|-----|--------|
| `Space` | Next page |
| `Enter` | Next line |
| `b` | Previous page (limited) |
| `d` | Half page forward |
| `q` | Quit |
| `/pattern` | Search forward |
| `n` | Next search match |
| `=` | Show current line number |
| `v` | Start editor at current line |
| `h` | Help |

## Examples

```bash
# View file with helpful prompts
$ more -d largefile.txt

# Start at line 100
$ more +100 logfile.txt

# Start at first occurrence of "ERROR"
$ more +/ERROR application.log

# Squeeze blank lines
$ more -s document.txt

# Clear screen before each page
$ more -p report.txt

# View command output
$ dmesg | more
$ ps aux | more
```

# less

The improved pager with full bidirectional scrolling, searching, and many advanced features. This is the recommended pager for most use cases.

## Basic Usage

```bash
# View a file
less filename.txt

# View multiple files
less file1.txt file2.txt

# Pipe command output
ls -la | less
cat largefile.txt | less

# Follow file updates (like tail -f)
less +F logfile.txt
```

## Common Flags

| Flag | Description |
|------|-------------|
| `-N` | Show line numbers |
| `-S` | Chop long lines (no wrap, scroll horizontally) |
| `-i` | Ignore case in searches |
| `-I` | Ignore case even if pattern has uppercase |
| `-M` | Show more detailed prompt |
| `-m` | Show percentage in prompt |
| `-F` | Quit if file fits on one screen |
| `-X` | Don't clear screen on exit |
| `-R` | Show ANSI color codes |
| `-s` | Squeeze consecutive blank lines |
| `+F` | Follow mode (like tail -f) |
| `+n` | Start at line n |
| `+/pattern` | Start at first match |
| `-p pattern` | Start at first match |
| `--follow-name` | Follow by filename (for rotating logs) |

## Navigation Keys

### Basic Movement

| Key | Action |
|-----|--------|
| `Space` / `Page Down` / `f` | Forward one page |
| `b` / `Page Up` | Backward one page |
| `d` | Forward half page |
| `u` | Backward half page |
| `j` / `Enter` / `Down` | Forward one line |
| `k` / `Up` | Backward one line |
| `g` / `Home` | Go to beginning |
| `G` / `End` | Go to end |
| `ng` | Go to line n |
| `nG` | Go to line n |
| `50p` or `50%` | Go to 50% of file |

### Searching

| Key | Action |
|-----|--------|
| `/pattern` | Search forward |
| `?pattern` | Search backward |
| `n` | Next match (same direction) |
| `N` | Next match (opposite direction) |
| `&pattern` | Show only matching lines |
| `Esc + u` | Undo search highlighting |

### Multiple Files

| Key | Action |
|-----|--------|
| `:n` | Next file |
| `:p` | Previous file |
| `:e filename` | Open new file |
| `:x` | Examine first file |

### Marks

| Key | Action |
|-----|--------|
| `ma` | Set mark 'a' at current position |
| `'a` | Go to mark 'a' |
| `''` | Go to previous position |

### Other

| Key | Action |
|-----|--------|
| `h` | Help |
| `q` | Quit |
| `v` | Edit file with $EDITOR |
| `F` | Follow mode (Ctrl+C to stop) |
| `-N` | Toggle line numbers |
| `-S` | Toggle line wrapping |
| `=` / `Ctrl+G` | File information |

## Examples

### Basic Viewing

```bash
# View with line numbers
$ less -N script.sh

# View without wrapping long lines
$ less -S wide_file.csv

# View with case-insensitive search
$ less -i logfile.txt

# Keep content on screen after exit
$ less -X file.txt

# View with ANSI colors preserved
$ ls --color=always | less -R
$ git diff | less -R
```

### Starting Position

```bash
# Start at line 500
$ less +500 largefile.log

# Start at first "ERROR"
$ less +/ERROR application.log
$ less -p ERROR application.log

# Start at end of file
$ less +G logfile.txt
```

### Log Monitoring

```bash
# Follow file updates (like tail -f)
$ less +F /var/log/syslog
# Press Ctrl+C to stop following, F to resume

# Follow with line numbers
$ less -N +F application.log

# Follow rotating logs
$ less --follow-name +F /var/log/messages
```

### Viewing Command Output

```bash
# View process list
$ ps aux | less

# View with colors
$ ls -la --color=always | less -R

# View git log
$ git log | less

# View man pages (uses less by default)
$ man bash
```

### Filtering Content

```bash
# Inside less, show only lines matching pattern
&ERROR        # Show only lines with "ERROR"
&             # Clear filter, show all lines

# Combine with grep before piping
$ grep -i error logfile.txt | less
```

### Multiple Files

```bash
# Open multiple files
$ less file1.txt file2.txt file3.txt
# Use :n and :p to navigate between files

# Open additional file while viewing
:e another_file.txt
```

## Environment Variables

```bash
# Set default options for less
export LESS='-R -N -M'

# Set default editor for 'v' command
export EDITOR=nano

# Set default pager system-wide
export PAGER=less
```

Add to `~/.bashrc` for persistence.

## Practical Use Cases

### Viewing Logs

```bash
# Monitor log in real-time
$ less +F /var/log/syslog

# Search for errors, case insensitive
$ less -i /var/log/application.log
/error

# View compressed logs
$ zless /var/log/syslog.2.gz
```

### Code Review

```bash
# View with line numbers
$ less -N source_code.py

# Navigate to specific function
/def function_name
```

### Large Files

```bash
# View without loading entire file
$ less huge_file.csv

# Jump to end to see latest entries
$ less +G large_log.txt
```

### CSV/Wide Files

```bash
# Don't wrap, scroll horizontally with arrow keys
$ less -S data.csv
```
