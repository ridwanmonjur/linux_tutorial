# ls - List Directory Contents

The `ls` command stands for **List**. It is the most common way to see what files and folders are inside your current directory.

---

## Basic Usage

```bash
# List files in current directory
ls

# List files in a specific directory
ls /path/to/folder

# List multiple directories
ls ~/Documents ~/Downloads
```

---

## Common Flags

### Display Format Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-l` | | Long format - shows permissions, owner, size, date |
| `-h` | `--human-readable` | Human-readable sizes (KB, MB, GB) - use with `-l` |
| `-1` | | One file per line |
| `-C` | | Multi-column output (default for terminal) |
| `-m` | | Comma-separated list |

### Filtering Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-a` | `--all` | Show hidden files (starting with `.`) |
| `-A` | `--almost-all` | Show hidden files except `.` and `..` |
| `-d` | `--directory` | List directories themselves, not their contents |
| `-R` | `--recursive` | List subdirectories recursively |

### Sorting Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-t` | | Sort by modification time (newest first) |
| `-S` | | Sort by file size (largest first) |
| `-r` | `--reverse` | Reverse the sort order |
| `-X` | | Sort alphabetically by extension |
| `-v` | | Natural sort of version numbers |
| `-f` | | Do not sort (faster for large directories) |

### Information Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-i` | `--inode` | Show inode numbers |
| `-s` | `--size` | Show allocated blocks |
| `-F` | `--classify` | Append indicator (*/=>@\|) to entries |
| `--color` | | Colorize output (auto/always/never) |

## Examples & Demos

### Basic Listing

```bash
# Simple list
$ ls
Documents  Downloads  Pictures  Videos

# Long format with human-readable sizes
$ ls -lh
total 16K
drwxr-xr-x 2 user user 4.0K Jan 15 10:30 Documents
drwxr-xr-x 2 user user 4.0K Jan 14 09:15 Downloads
drwxr-xr-x 2 user user 4.0K Jan 10 14:22 Pictures
drwxr-xr-x 2 user user 4.0K Jan 12 16:45 Videos
```

### Hidden Files

```bash
# Show all files including hidden
$ ls -la
total 32K
drwxr-xr-x 6 user user 4.0K Jan 15 10:30 .
drwxr-xr-x 3 root root 4.0K Jan 01 00:00 ..
-rw-r--r-- 1 user user  220 Jan 01 00:00 .bash_logout
-rw-r--r-- 1 user user 3.5K Jan 01 00:00 .bashrc
drwxr-xr-x 2 user user 4.0K Jan 15 10:30 Documents
```

### Sorting

```bash
# Sort by time, newest first
$ ls -lt
total 16K
drwxr-xr-x 2 user user 4.0K Jan 15 10:30 Documents
drwxr-xr-x 2 user user 4.0K Jan 14 09:15 Downloads
drwxr-xr-x 2 user user 4.0K Jan 12 16:45 Videos
drwxr-xr-x 2 user user 4.0K Jan 10 14:22 Pictures

# Sort by size, largest first
$ ls -lhS
total 1.2M
-rw-r--r-- 1 user user 500K Jan 15 10:30 large_file.zip
-rw-r--r-- 1 user user 200K Jan 14 09:15 medium_file.tar
-rw-r--r-- 1 user user  50K Jan 10 14:22 small_file.txt

# Reverse sort (oldest first)
$ ls -ltr
```

### Recursive & Directory Listing

```bash
# Recursive listing
$ ls -R projects/
projects/:
src  docs  README.md

projects/src:
main.c  utils.c

projects/docs:
manual.md

# List only directories
$ ls -d */
Documents/  Downloads/  Pictures/  Videos/
```

### File Type Indicators

```bash
# Show file type indicators
$ ls -F
Documents/  Downloads/  script.sh*  link@  pipe|

# Legend:
# /  = directory
# *  = executable
# @  = symbolic link
# |  = named pipe
# =  = socket
```

### Advanced Combinations

```bash
# Fast listing (no sort) for directories with many files
$ ls -f /var/log

# Combine multiple flags
$ ls -lahtr
# -l: long format
# -a: all files
# -h: human-readable
# -t: sort by time
# -r: reverse (oldest first)

# Show inode numbers
$ ls -li
1234567 -rw-r--r-- 1 user user 1024 Jan 15 file.txt
```

