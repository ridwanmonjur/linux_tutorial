# head & tail - View File Beginnings and Endings

`head` and `tail` are complementary commands for viewing portions of files. `head` shows the beginning, `tail` shows the end. Both are essential for working with logs, large files, and data processing.

---

## Quick Comparison

| Feature | `head` | `tail` |
|---------|--------|--------|
| Default lines | First 10 | Last 10 |
| Follow updates | No | Yes (`-f`) |
| Common use | File headers, CSV columns | Log monitoring |

---

# head

Displays the first part of files. By default, shows the first 10 lines.

## Basic Usage

```bash
# Show first 10 lines (default)
head filename.txt

# Show first n lines
head -n 20 filename.txt
head -20 filename.txt

# Show first n bytes
head -c 100 filename.txt
```

## Common Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-n NUM` | `--lines=NUM` | Output first NUM lines |
| `-c NUM` | `--bytes=NUM` | Output first NUM bytes |
| `-q` | `--quiet` | Never print headers (multiple files) |
| `-v` | `--verbose` | Always print headers |
| `-z` | `--zero-terminated` | Line delimiter is NUL, not newline |

### Negative Numbers

| Flag | Description |
|------|-------------|
| `-n -NUM` | All BUT the last NUM lines |
| `-c -NUM` | All BUT the last NUM bytes |

## Examples

### Basic Usage

```bash
# First 10 lines (default)
$ head file.txt

# First 20 lines
$ head -n 20 file.txt
$ head -20 file.txt

# First 5 lines
$ head -n 5 document.txt

# First line only
$ head -n 1 file.txt
$ head -1 file.txt
```

### Byte-Based

```bash
# First 100 bytes
$ head -c 100 file.txt

# First 1 KB
$ head -c 1K file.txt

# First 1 MB
$ head -c 1M largefile.bin

# First 1 GB (useful for splitting)
$ head -c 1G hugefile.bin > first_part.bin
```

### Negative Values (Exclude End)

```bash
# All lines EXCEPT last 5
$ head -n -5 file.txt

# All bytes EXCEPT last 100
$ head -c -100 file.txt

# Remove last line (useful for removing trailing newline)
$ head -n -1 file.txt
```

### Multiple Files

```bash
# View multiple files (shows headers by default)
$ head file1.txt file2.txt
==> file1.txt <==
First 10 lines of file1...

==> file2.txt <==
First 10 lines of file2...

# Suppress headers
$ head -q file1.txt file2.txt

# Force headers even for single file
$ head -v file.txt
```

### Practical Examples

```bash
# Preview CSV structure
$ head -n 5 data.csv
id,name,email,date
1,John,john@example.com,2026-01-01
2,Jane,jane@example.com,2026-01-02

# Check file encoding/format
$ head -c 20 file.txt | xxd

# Get header row of CSV
$ head -n 1 data.csv > header.csv

# Split file at specific line
$ head -n 1000 largefile.txt > first_1000.txt
$ tail -n +1001 largefile.txt > rest.txt
```

# tail

Displays the last part of files. By default, shows the last 10 lines. Most famous for its `-f` flag to follow log files in real-time.

## Basic Usage

```bash
# Show last 10 lines (default)
tail filename.txt

# Show last n lines
tail -n 20 filename.txt
tail -20 filename.txt

# Show last n bytes
tail -c 100 filename.txt

# Follow file updates (real-time monitoring)
tail -f logfile.txt
```

## Common Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-n NUM` | `--lines=NUM` | Output last NUM lines |
| `-c NUM` | `--bytes=NUM` | Output last NUM bytes |
| `-f` | `--follow` | Follow file as it grows |
| `-F` | `--follow --retry` | Follow and retry if file unavailable |
| `-q` | `--quiet` | Never print headers |
| `-v` | `--verbose` | Always print headers |
| `--pid=PID` | | Terminate after process PID dies |
| `-s SEC` | `--sleep-interval=SEC` | Sleep SEC seconds between follow updates |

### Starting Position

| Flag | Description |
|------|-------------|
| `-n +NUM` | Start at line NUM (skip first NUM-1 lines) |
| `-c +NUM` | Start at byte NUM |

## Examples

### Basic Usage

```bash
# Last 10 lines (default)
$ tail file.txt

# Last 20 lines
$ tail -n 20 file.txt
$ tail -20 file.txt

# Last 100 lines
$ tail -n 100 access.log

# Last 5 lines
$ tail -n 5 document.txt
```

### Starting from Position (Skip Beginning)

```bash
# Start from line 10 (skip first 9 lines)
$ tail -n +10 file.txt

# Skip header row of CSV
$ tail -n +2 data.csv

# Start from byte 100
$ tail -c +100 file.txt
```

### Byte-Based

```bash
# Last 100 bytes
$ tail -c 100 file.txt

# Last 1 KB
$ tail -c 1K file.txt

# Last 1 MB of log
$ tail -c 1M largelog.txt
```

### Following Files (Real-time Monitoring)

```bash
# Follow file updates
$ tail -f /var/log/syslog

# Follow multiple files
$ tail -f file1.log file2.log

# Follow with filename headers
$ tail -fv access.log error.log

# Follow with retry (for rotating logs)
$ tail -F /var/log/messages

# Follow until process exits
$ tail -f logfile.txt --pid=$PID

# Follow with custom interval (every 2 seconds)
$ tail -f -s 2 slowlog.txt
```

### Practical Examples

```bash
# Monitor Apache access log
$ tail -f /var/log/apache2/access.log

# Monitor with grep filter
$ tail -f application.log | grep -i error

# Monitor with highlighting
$ tail -f app.log | grep --color=always -E 'ERROR|WARNING|$'

# Monitor multiple logs
$ tail -f /var/log/{syslog,auth.log}

# Last 1000 lines, then follow
$ tail -n 1000 -f application.log

# Get lines 50-100 of a file
$ head -n 100 file.txt | tail -n 51
# Or
$ sed -n '50,100p' file.txt
```

### Multiple Files

```bash
# View last 5 lines of multiple files
$ tail -n 5 *.log

# Suppress headers
$ tail -q -n 5 file1.txt file2.txt

# Force headers
$ tail -v file.txt
```

## Combining head and tail

```bash
# Lines 50-60 of a file
$ head -n 60 file.txt | tail -n 11

# Middle portion of file
$ sed -n '100,200p' file.txt  # Alternative method

# Remove first and last line
$ tail -n +2 file.txt | head -n -1

# Get line 50 only
$ head -n 50 file.txt | tail -n 1
$ sed -n '50p' file.txt  # Alternative
```

---

## Common Patterns

### Log Analysis

```bash
# Last 100 errors
$ grep ERROR application.log | tail -n 100

# Recent errors with context
$ tail -n 1000 app.log | grep -B2 -A2 ERROR

# Count recent occurrences
$ tail -n 1000 access.log | grep "404" | wc -l
```

### File Processing

```bash
# Skip CSV header
$ tail -n +2 data.csv > data_no_header.csv

# Get header and last 10 data rows
$ head -n 1 data.csv && tail -n 10 data.csv

# Process all but first line
$ tail -n +2 data.csv | while read line; do
    echo "Processing: $line"
done
```

### Splitting Files

```bash
# Split at line 1000
$ head -n 1000 file.txt > part1.txt
$ tail -n +1001 file.txt > part2.txt

# Get chunks
$ head -n 500 file.txt > first_500.txt
$ tail -n +501 file.txt | head -n 500 > second_500.txt
```

---

## Differences: tail -f vs tail -F

| Feature | `tail -f` | `tail -F` |
|---------|-----------|-----------|
| Follow file | Yes | Yes |
| Retry if missing | No | Yes |
| Handle log rotation | No | Yes |
| Use case | Regular files | Rotating logs |

```bash
# Regular log following
$ tail -f myapp.log

# Rotating log following (restarts when file rotates)
$ tail -F /var/log/syslog
```

---

## Watch Alternative

For periodic updates (not continuous):

```bash
# Update every 2 seconds
$ watch -n 2 'tail -n 20 logfile.txt'

# With differences highlighted
$ watch -d 'tail -n 20 logfile.txt'
```

---

> **Pro Tip:** Use `tail -f logfile.txt | grep --line-buffered pattern` to filter real-time logs. The `--line-buffered` ensures immediate output.
