# File Permissions - chmod, chown, and rwx

Understanding Linux file permissions is essential for system security and proper file management.

---

## Understanding rwx Notation

Every file and directory has permissions for three categories of users:

| Category | Symbol | Description |
|----------|--------|-------------|
| Owner | u | The user who owns the file |
| Group | g | Users in the file's group |
| Others | o | Everyone else |
| All | a | All three categories |

### Permission Types

| Permission | Symbol | Numeric | For Files | For Directories |
|------------|--------|---------|-----------|-----------------|
| Read | r | 4 | View contents | List contents |
| Write | w | 2 | Modify contents | Create/delete files |
| Execute | x | 1 | Run as program | Enter directory |

### Reading Permission String

```
-rwxr-xr--
│└┬┘└┬┘└┬┘
│ │  │  └── Others: read only (r--)
│ │  └───── Group: read and execute (r-x)
│ └──────── Owner: read, write, execute (rwx)
└────────── File type (- = file, d = directory, l = link)
```

### File Types

| Symbol | Type |
|--------|------|
| `-` | Regular file |
| `d` | Directory |
| `l` | Symbolic link |
| `c` | Character device |
| `b` | Block device |
| `s` | Socket |
| `p` | Named pipe |

## Numeric (Octal) Permissions

Each permission has a numeric value:

| Permission | Value |
|------------|-------|
| Read (r) | 4 |
| Write (w) | 2 |
| Execute (x) | 1 |
| None (-) | 0 |

Add values for combined permissions:

| Numeric | Symbolic | Meaning |
|---------|----------|---------|
| 7 | rwx | Read + Write + Execute |
| 6 | rw- | Read + Write |
| 5 | r-x | Read + Execute |
| 4 | r-- | Read only |
| 3 | -wx | Write + Execute |
| 2 | -w- | Write only |
| 1 | --x | Execute only |
| 0 | --- | No permissions |

### Common Permission Sets

| Numeric | Symbolic | Typical Use |
|---------|----------|-------------|
| 755 | rwxr-xr-x | Executables, directories |
| 644 | rw-r--r-- | Regular files |
| 600 | rw------- | Private files |
| 700 | rwx------ | Private directories/scripts |
| 777 | rwxrwxrwx | Full access (avoid!) |
| 666 | rw-rw-rw- | Read/write for all (avoid!) |
| 750 | rwxr-x--- | Group-shared directories |
| 640 | rw-r----- | Group-readable files |

## chmod - Change File Mode

### Symbolic Mode

```bash
chmod [who][operator][permissions] file
```

**Who:** u (user/owner), g (group), o (others), a (all)
**Operator:** + (add), - (remove), = (set exactly)
**Permissions:** r, w, x

```bash
# Add execute for owner
chmod u+x script.sh

# Remove write for group and others
chmod go-w file.txt

# Set exact permissions
chmod u=rwx,g=rx,o=r file.txt

# Add execute for all
chmod a+x script.sh
chmod +x script.sh    # Same (a is default)

# Remove all permissions for others
chmod o= file.txt
chmod o-rwx file.txt  # Same

# Copy permissions from another category
chmod g=u file.txt    # Group gets same as user
```

### Numeric Mode

```bash
chmod [mode] file
```

```bash
# Standard file permissions
chmod 644 file.txt      # rw-r--r--

# Executable script
chmod 755 script.sh     # rwxr-xr-x

# Private file
chmod 600 secrets.txt   # rw-------

# Private directory
chmod 700 private/      # rwx------

# Shared directory
chmod 775 shared/       # rwxrwxr-x
```

### Recursive Changes

```bash
# Change all files and directories recursively
chmod -R 755 directory/

# Change only files (using find)
find /path -type f -exec chmod 644 {} \;

# Change only directories
find /path -type d -exec chmod 755 {} \;
```

### Common Flags

| Flag | Description |
|------|-------------|
| `-R` | Recursive (include subdirectories) |
| `-v` | Verbose (show changes) |
| `-c` | Like verbose but only show changes |
| `--reference=file` | Copy permissions from another file |

### Examples

```bash
# Make script executable
chmod +x install.sh

# Secure a config file
chmod 600 .env

# Fix web directory permissions
chmod -R 755 /var/www/html/

# Copy permissions from another file
chmod --reference=file1.txt file2.txt

# Remove execute from all files, add to directories
find . -type f -exec chmod -x {} \;
find . -type d -exec chmod +x {} \;
```

## chown - Change Ownership

### Basic Syntax

```bash
chown [owner][:group] file
```

### Examples

```bash
# Change owner
chown john file.txt

# Change owner and group
chown john:developers file.txt

# Change only group (note the colon)
chown :developers file.txt

# Change recursively
chown -R john:developers project/

# Using user ID and group ID
chown 1000:1000 file.txt
```

### Common Flags

| Flag | Description |
|------|-------------|
| `-R` | Recursive |
| `-v` | Verbose |
| `-c` | Report only changes |
| `--reference=file` | Copy ownership from another file |
| `-h` | Change symlink ownership (not target) |

### Practical Examples

```bash
# Change web files to web server user
sudo chown -R www-data:www-data /var/www/html/

# Fix home directory ownership
sudo chown -R username:username /home/username/

# Transfer file ownership
sudo chown newuser:newgroup important_file.txt

# Copy ownership from reference file
sudo chown --reference=/home/john /home/john/newfile
```

---

## chgrp - Change Group Only

Alternative to `chown :group`:

```bash
# Change group
chgrp developers file.txt

# Recursive
chgrp -R developers project/
```

## Special Permissions

### Setuid (4)

When set on executable: runs with owner's permissions, not executor's.

```bash
# View setuid files (s in owner execute position)
ls -l /usr/bin/passwd
-rwsr-xr-x 1 root root ... /usr/bin/passwd

# Set setuid
chmod u+s executable
chmod 4755 executable
```

### Setgid (2)

- On executable: runs with group's permissions
- On directory: new files inherit directory's group

```bash
# Set setgid on directory
chmod g+s shared_folder/
chmod 2775 shared_folder/

# View (s in group execute position)
ls -ld shared_folder/
drwxrwsr-x 2 john developers ... shared_folder/
```

### Sticky Bit (1)

On directory: only owner can delete their files (used on /tmp).

```bash
# Set sticky bit
chmod +t directory/
chmod 1777 directory/

# View (t in others execute position)
ls -ld /tmp
drwxrwxrwt 10 root root ... /tmp
```

### Special Permission Examples

```bash
# Full notation with special permissions
chmod 4755 setuid_program    # Setuid + rwxr-xr-x
chmod 2755 shared_dir        # Setgid + rwxr-xr-x
chmod 1777 /tmp              # Sticky + rwxrwxrwx

# Combined
chmod 6755 program           # Setuid + Setgid + rwxr-xr-x
```

## Viewing Permissions

### Using ls

```bash
# List with permissions
ls -l

# List all files (including hidden)
ls -la

# List directories themselves
ls -ld directory/

# Human-readable with permissions
ls -lh
```

### Using stat

```bash
# Detailed file info
stat file.txt

# Show only permissions
stat -c "%a %n" file.txt    # Numeric
stat -c "%A %n" file.txt    # Symbolic
```

### Using getfacl

```bash
# Show Access Control Lists (more detailed)
getfacl file.txt
```

## Default Permissions (umask)

umask sets default permissions for new files.

```bash
# View current umask
umask

# Set umask
umask 022    # New files: 644, new dirs: 755
umask 077    # New files: 600, new dirs: 700
```

| umask | File Result | Directory Result |
|-------|-------------|------------------|
| 000 | 666 | 777 |
| 022 | 644 | 755 |
| 027 | 640 | 750 |
| 077 | 600 | 700 |

> Note: Files never get execute by default (max 666), directories do (max 777).

## Common Scenarios

### Web Server Files

```bash
# Apache/Nginx typical setup
sudo chown -R www-data:www-data /var/www/html
sudo find /var/www/html -type d -exec chmod 755 {} \;
sudo find /var/www/html -type f -exec chmod 644 {} \;
```

### Shared Development Directory

```bash
# Create group and directory
sudo groupadd developers
sudo mkdir /projects
sudo chown root:developers /projects
sudo chmod 2775 /projects    # Setgid for group inheritance
```

### Private SSH Keys

```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_rsa
chmod 644 ~/.ssh/id_rsa.pub
chmod 600 ~/.ssh/authorized_keys
```

### Executable Script

```bash
chmod 755 script.sh
# or
chmod u+x script.sh
```

### Config File with Secrets

```bash
chmod 600 config.ini
chmod 600 .env
```

## Quick Reference

| Task | Command |
|------|---------|
| Make executable | `chmod +x file` |
| Remove write for others | `chmod o-w file` |
| Set standard file permissions | `chmod 644 file` |
| Set standard directory permissions | `chmod 755 dir` |
| Make private | `chmod 600 file` |
| Change owner | `chown user file` |
| Change owner and group | `chown user:group file` |
| Change group only | `chgrp group file` |
| Recursive permission change | `chmod -R 755 dir` |
| View permissions | `ls -l file` |

```bash
# Check file permissions
ls -la problematic_file

# Check parent directory permissions
ls -la $(dirname problematic_file)

# Check your user and groups
id

# Check file owner
stat problematic_file
```
