# rmdir - Remove Empty Directories

The `rmdir` (remove directory) command is a safety-oriented utility used specifically to delete empty directories. It will refuse to delete directories that contain any files.

---

## Basic Usage

```bash
# Remove a single empty directory
rmdir empty_folder

# Remove multiple empty directories
rmdir dir1 dir2 dir3
```

---

## Common Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-p` | `--parents` | Remove directory and its empty ancestors |
| `-v` | `--verbose` | Output a diagnostic for every directory processed |
| | `--ignore-fail-on-non-empty` | Suppress error for non-empty directories |

---

## Examples & Demos

### Basic Removal

```bash
# Remove a single empty directory
$ rmdir empty_folder

# Remove multiple empty directories
$ rmdir dir1 dir2 dir3

# Attempt to remove non-empty directory (will fail)
$ rmdir folder_with_files
rmdir: failed to remove 'folder_with_files': Directory not empty
```

### Verbose Output

```bash
# Remove with verbose output
$ rmdir -v test_folder
rmdir: removing directory, 'test_folder'

# Multiple directories with verbose
$ rmdir -v dir1 dir2 dir3
rmdir: removing directory, 'dir1'
rmdir: removing directory, 'dir2'
rmdir: removing directory, 'dir3'
```

### Removing Parent Directories

```bash
# Remove nested empty directories
$ rmdir -p a/b/c
# Removes c, then b, then a (if each is empty after removal)

# Remove nested with verbose
$ rmdir -pv project/temp/cache
rmdir: removing directory, 'project/temp/cache'
rmdir: removing directory, 'project/temp'
rmdir: removing directory, 'project'

# If a parent isn't empty, it stops there
$ rmdir -pv data/2024/jan
rmdir: removing directory, 'data/2024/jan'
rmdir: removing directory, 'data/2024'
rmdir: failed to remove 'data': Directory not empty
```

### Ignoring Errors

```bash
# Ignore errors for non-empty directories
$ rmdir --ignore-fail-on-non-empty folder_with_files
# No error message, but directory is not deleted

# Useful in scripts to avoid error exit codes
$ rmdir --ignore-fail-on-non-empty dir1 dir2 dir3
```

### Practical Examples

```bash
# Clean up empty build directories
$ rmdir -v build/*/

# Remove temporary directories after processing
$ rmdir -pv temp/processing/session_123

# Clean up empty log rotation directories
$ rmdir -v /var/log/app/2024/*/
```

---

## rmdir vs rm -r Comparison

| Feature | `rmdir` | `rm -r` |
|---------|---------|---------|
| Safety | High - won't delete directories with files | Low - deletes everything inside |
| Non-empty folders | Fails with "Directory not empty" | Deletes the folder and all contents |
| Recursive deletion | Only for empty parents with `-p` | Deletes entire trees regardless of content |
| Risk level | Minimal | High |
| Use case | Safe cleanup of empty dirs | Removing files and directories |

---

## When to Use rmdir

### Safe Directory Cleanup
```bash
# After moving files out, clean up empty structure
$ mv project/old/* project/archive/
$ rmdir -pv project/old
```

### Script Safety
```bash
#!/bin/bash
# Safely remove directory only if empty
if rmdir "$DIR" 2>/dev/null; then
    echo "Removed empty directory: $DIR"
else
    echo "Directory not empty or doesn't exist: $DIR"
fi
```

### Build Cleanup
```bash
# Remove empty build artifacts directories
$ find build/ -type d -empty -exec rmdir -v {} \;
```

---

## Common Errors

```bash
# Directory not empty
$ rmdir folder/
rmdir: failed to remove 'folder/': Directory not empty
# Solution: Use rm -r if you want to delete contents

# Directory doesn't exist
$ rmdir nonexistent/
rmdir: failed to remove 'nonexistent/': No such file or directory

# Permission denied
$ rmdir /etc/some_dir/
rmdir: failed to remove '/etc/some_dir/': Permission denied
# Solution: Use sudo if appropriate
```

---

> **Pro Tip:** Use `rmdir` when you want to ensure you're only deleting empty directories. The failure on non-empty directories is a safety feature, not a bug.
