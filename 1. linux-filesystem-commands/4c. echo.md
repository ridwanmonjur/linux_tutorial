# echo - Print Text & Write to Files

The `echo` command is the most common way to print text to the terminal or write it to files. It's the "voice" of your Linux system and scripts.

---

## Basic Usage

```bash
# Print text to terminal
echo "Hello World"

# Print without trailing newline
echo -n "Enter name: "

# Enable escape sequences
echo -e "Line1\nLine2"
```

---

## Common Flags

| Flag | Description |
|------|-------------|
| `-n` | Do not output trailing newline |
| `-e` | Enable interpretation of escape sequences |
| `-E` | Disable interpretation of escape sequences (default) |

---

## Escape Sequences (with -e)

| Sequence | Description |
|----------|-------------|
| `\n` | Newline |
| `\t` | Horizontal tab |
| `\r` | Carriage return |
| `\b` | Backspace |
| `\\` | Backslash |
| `\a` | Alert (bell) |
| `\e` | Escape character (for colors) |
| `\0nnn` | Octal value |
| `\xHH` | Hexadecimal value |

## Examples & Demos

### Basic Output

```bash
# Simple text output
$ echo "Hello World"
Hello World

# Without trailing newline
$ echo -n "Enter name: "
Enter name: _

# Empty line
$ echo

# Multiple words without quotes
$ echo Hello World
Hello World
```

### Using Escape Sequences

```bash
# Multiple lines
$ echo -e "Line 1\nLine 2\nLine 3"
Line 1
Line 2
Line 3

# With tabs (formatted output)
$ echo -e "Name:\tJohn\nAge:\t25\nCity:\tNew York"
Name:	John
Age:	25
City:	New York

# Backspace (removes previous character)
$ echo -e "Hello\b World"
Hell World

# Carriage return (overwrites from beginning)
$ echo -e "XXXX\rOK"
OK

# Alert/bell sound
$ echo -e "\aBeep!"
```

### Writing to Files

```bash
# Create/overwrite file
$ echo "Hello World" > file.txt

# Append to file
$ echo "New line" >> file.txt

# Multiple lines to file
$ echo -e "Line 1\nLine 2\nLine 3" > multiline.txt

# Empty file (truncate)
$ echo -n > empty_file.txt
# Or simply:
$ > empty_file.txt
```

### Variables and Commands

```bash
# Display environment variables
$ echo $USER
john

$ echo $HOME
/home/john

$ echo $PATH
/usr/local/bin:/usr/bin:/bin

$ echo $SHELL
/bin/bash

$ echo $PWD
/home/john/projects

# Combine text and variables
$ echo "Current user: $USER"
Current user: john

$ echo "Home directory is $HOME"
Home directory is /home/john

# Command substitution
$ echo "Today is $(date)"
Today is Fri Feb 14 10:30:00 EST 2026

$ echo "Current directory: $(pwd)"
Current directory: /home/john/projects

$ echo "Files here: $(ls | wc -l)"
Files here: 42

# Arithmetic
$ echo "2 + 2 = $((2 + 2))"
2 + 2 = 4
```

### Colors (ANSI Escape Codes)

```bash
# Basic colors
$ echo -e "\e[31mRed text\e[0m"
$ echo -e "\e[32mGreen text\e[0m"
$ echo -e "\e[33mYellow text\e[0m"
$ echo -e "\e[34mBlue text\e[0m"
$ echo -e "\e[35mMagenta text\e[0m"
$ echo -e "\e[36mCyan text\e[0m"

# Bright colors
$ echo -e "\e[91mBright Red\e[0m"
$ echo -e "\e[92mBright Green\e[0m"

# Text styles
$ echo -e "\e[1mBold text\e[0m"
$ echo -e "\e[4mUnderlined text\e[0m"
$ echo -e "\e[7mInverted colors\e[0m"
$ echo -e "\e[9mStrikethrough\e[0m"

# Combined styles
$ echo -e "\e[1;31mBold Red Text\e[0m"
$ echo -e "\e[4;34mUnderlined Blue\e[0m"

# Background colors
$ echo -e "\e[41mRed background\e[0m"
$ echo -e "\e[42mGreen background\e[0m"
$ echo -e "\e[44mBlue background\e[0m"

# Foreground on background
$ echo -e "\e[31;43mRed on Yellow\e[0m"
$ echo -e "\e[37;44mWhite on Blue\e[0m"
```

## Quoting Rules

```bash
# Double quotes - variables ARE expanded
$ echo "Home is $HOME"
Home is /home/john

# Single quotes - variables NOT expanded (literal)
$ echo 'Home is $HOME'
Home is $HOME

# Escape dollar sign in double quotes
$ echo "Price is \$100"
Price is $100

# Escape backslash
$ echo "Path: C:\\Users\\Name"
Path: C:\Users\Name

# Mixed quoting
$ echo "User: $USER"' Path: $PATH'
User: john Path: $PATH

# Preserve special characters
$ echo 'Use `backticks` for commands'
Use `backticks` for commands
```

## Practical Examples

### Script Headers

```bash
#!/bin/bash
echo "================================"
echo "  My Awesome Script v1.0"
echo "================================"
echo ""
```

### User Prompts

```bash
echo -n "Enter your name: "
read name
echo "Hello, $name!"
```

### Colored Status Messages

```bash
# Success message
echo -e "\e[32m[SUCCESS]\e[0m Operation completed"

# Warning message
echo -e "\e[33m[WARNING]\e[0m Check your input"

# Error message
echo -e "\e[31m[ERROR]\e[0m Something went wrong"
```

### Creating Config Files

```bash
# Create .env file
echo "DATABASE_URL=localhost:5432" > .env
echo "API_KEY=your_key_here" >> .env
echo "DEBUG=true" >> .env
```

### Debug Output

```bash
# Print variable values for debugging
echo "DEBUG: username=$username"
echo "DEBUG: config_path=$config_path"
```

## Writing to System Files

```bash
# This WON'T work (redirection runs as user)
$ sudo echo "text" > /etc/config
# Permission denied

# Use tee instead
$ echo "text" | sudo tee /etc/config

# Append with tee
$ echo "text" | sudo tee -a /etc/config
```

---

## printf Alternative

For more control over formatting, use `printf`:

```bash
# Formatted output
$ printf "Name: %s, Age: %d\n" "John" 25
Name: John, Age: 25

# Width specification
$ printf "%-10s %5d\n" "Item" 100
Item         100

# Float formatting
$ printf "%.2f\n" 3.14159
3.14
```

---

> **Pro Tip:** If you need to write to a file requiring root permissions, use `echo "text" | sudo tee /etc/config` instead of `sudo echo "text" > /etc/config` (which won't work).
