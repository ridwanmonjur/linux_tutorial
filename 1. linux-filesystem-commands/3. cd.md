# cd - Change Directory

The `cd` (change directory) command is a shell builtin used to navigate the file system. While primarily used with directory paths, it supports specific flags that change how it handles symbolic links.

---

## Basic Usage

```bash
# Navigate to a directory
cd /path/to/directory

# Navigate to home directory
cd
cd ~
cd $HOME
```

---

## Core Command Flags

| Flag | Description |
|------|-------------|
| `-L` | Follow symbolic links (default behavior) |
| `-P` | Resolve symbolic links to their physical directory |
| `-e` | Exit with error if physical path cannot be determined (use with `-P`) |
| `-@` | Show extended attributes (macOS) |

---

## Navigation Shortcuts

| Shortcut | Description |
|----------|-------------|
| `cd ..` | Move up to parent directory |
| `cd ~` or `cd` | Return to home directory |
| `cd -` | Switch to previous directory |
| `cd /` | Navigate to root directory |
| `cd ../..` | Move up two directories |
| `cd ~username` | Go to another user's home directory |

---

## Examples & Demos

### Basic Navigation

```bash
# Navigate to a directory
$ cd /var/log

# Go to home directory (three equivalent ways)
$ cd
$ cd ~
$ cd $HOME

# Go up one level
$ cd ..

# Go up multiple levels
$ cd ../../..

# Navigate to root
$ cd /
```

### Previous Directory

```bash
# Switch to previous directory
$ cd /etc
$ cd /var
$ cd -
/etc

# Toggle between two directories
$ cd -
/var
$ cd -
/etc
```

### Symbolic Links

```bash
# Create a symbolic link for demonstration
$ ln -s /home/user/projects /tmp/mylink

# Logical path (follows symlink - default)
$ cd -L /tmp/mylink
$ pwd
/tmp/mylink

# Physical path (resolves symlink)
$ cd -P /tmp/mylink
$ pwd
/home/user/projects

# Error if physical path fails (with -e)
$ cd -Pe /tmp/broken_link
bash: cd: /tmp/broken_link: No such file or directory
```

### Paths with Spaces

```bash
# Using quotes
$ cd "My Documents"

# Using escape character
$ cd My\ Documents

# Using tab completion (recommended)
$ cd My<TAB>
$ cd My\ Documents/
```

### Using Variables

```bash
# Navigate using environment variables
$ cd $HOME/Documents

# Using custom variables
$ PROJECT_DIR=/home/user/projects
$ cd $PROJECT_DIR

# Using command substitution
$ cd $(dirname /path/to/file.txt)
```

### Useful Patterns

```bash
# Go to project root (if using git)
$ cd $(git rev-parse --show-toplevel)

# Navigate to directory of a file
$ cd "$(dirname "$filepath")"

# Create and enter directory
$ mkdir newdir && cd newdir

# Using CDPATH for quick navigation
$ export CDPATH=.:~:~/projects
$ cd myproject  # Finds ~/projects/myproject automatically
```

---

## CDPATH Variable

Set directories to search when using `cd`:

```bash
# Add to ~/.bashrc
export CDPATH=.:~:~/projects:~/Documents

# Now you can navigate directly
$ cd myproject    # Finds ~/projects/myproject
$ cd notes        # Finds ~/Documents/notes
```

---

## Pushd and Popd (Directory Stack)

For complex navigation, use the directory stack:

```bash
# Push current directory and change
$ pushd /var/log
/var/log ~ /etc

# Push another directory
$ pushd /etc/nginx
/etc/nginx /var/log ~ /etc

# Pop back to previous
$ popd
/var/log ~ /etc

# View directory stack
$ dirs -v
0  /var/log
1  ~
2  /etc
```

---

> **Pro Tip:** Use the `Tab` key to autocomplete directory names to avoid typos.
