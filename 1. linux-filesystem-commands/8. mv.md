# mv - Move and Rename Files

The `mv` (move) command moves files and directories from one location to another. It's also the standard way to rename files in Linux.

---

## Basic Usage

```bash
# Move file to directory
mv file.txt /path/to/directory/

# Rename file
mv oldname.txt newname.txt

# Move and rename
mv file.txt /path/to/directory/newname.txt

# Move multiple files to directory
mv file1.txt file2.txt file3.txt /path/to/directory/
```

---

## Common Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-i` | `--interactive` | Prompt before overwriting |
| `-f` | `--force` | Never prompt (overwrite silently) |
| `-n` | `--no-clobber` | Never overwrite existing files |
| `-u` | `--update` | Move only when source is newer |
| `-v` | `--verbose` | Explain what is being done |
| `-b` | `--backup` | Make backup of existing destination files |
| `-S` | `--suffix=SUFFIX` | Override backup suffix (default ~) |
| `-t` | `--target-directory=DIR` | Move all sources to DIR |
| `-T` | `--no-target-directory` | Treat destination as normal file |

## Examples & Demos

### Renaming Files

```bash
# Simple rename
$ mv oldname.txt newname.txt

# Rename with verbose
$ mv -v report.txt final_report.txt
renamed 'report.txt' -> 'final_report.txt'

# Change extension
$ mv document.txt document.md

# Rename directory
$ mv old_folder new_folder
```

### Moving Files

```bash
# Move single file to directory
$ mv file.txt Documents/

# Move to directory (explicit)
$ mv file.txt /home/user/Documents/

# Move multiple files
$ mv file1.txt file2.txt file3.txt backup/

# Move all .txt files
$ mv *.txt Documents/

# Move all files matching pattern
$ mv report_*.pdf archive/
```

### Move and Rename

```bash
# Move to different directory with new name
$ mv ~/Downloads/photo.jpg ~/Pictures/vacation_2026.jpg

# Move with directory change
$ mv src/old_module.py src/utils/helper.py
```

### Interactive Mode (Safety)

```bash
# Prompt before overwriting
$ mv -i source.txt destination.txt
mv: overwrite 'destination.txt'? y

# Always prompt for multiple files
$ mv -i *.txt backup/
mv: overwrite 'backup/file1.txt'? y
mv: overwrite 'backup/file2.txt'? n
```

### Prevent Overwriting

```bash
# Never overwrite existing files
$ mv -n source.txt existing.txt
# Silent - doesn't overwrite, no error

# Move only if source is newer
$ mv -u source.txt destination.txt

# No clobber with verbose
$ mv -nv *.txt backup/
```

### Backup Existing Files

```bash
# Create backup before overwriting
$ mv -b source.txt destination.txt
# Creates destination.txt~ if destination.txt exists

# Custom backup suffix
$ mv -b -S .bak source.txt destination.txt
# Creates destination.txt.bak

# Numbered backups
$ mv --backup=numbered source.txt destination.txt
# Creates destination.txt.~1~, destination.txt.~2~, etc.
```

### Using Target Directory

```bash
# Specify target directory (useful in scripts)
$ mv -t /backup/ file1.txt file2.txt file3.txt

# Equivalent to
$ mv file1.txt file2.txt file3.txt /backup/

# Useful with find/xargs
$ find . -name "*.log" -print0 | xargs -0 mv -t /logs/
```

### Verbose Output

```bash
# Show what's happening
$ mv -v file.txt Documents/
renamed 'file.txt' -> 'Documents/file.txt'

# Verbose with multiple files
$ mv -v *.jpg Pictures/
renamed 'photo1.jpg' -> 'Pictures/photo1.jpg'
renamed 'photo2.jpg' -> 'Pictures/photo2.jpg'
renamed 'photo3.jpg' -> 'Pictures/photo3.jpg'
```

## Batch Operations

### Rename Multiple Files

```bash
# Using a loop
$ for f in *.txt; do
    mv "$f" "${f%.txt}.md"
done

# Add prefix
$ for f in *.jpg; do
    mv "$f" "vacation_$f"
done

# Add date prefix
$ for f in *.log; do
    mv "$f" "$(date +%Y%m%d)_$f"
done

# Remove prefix
$ for f in prefix_*; do
    mv "$f" "${f#prefix_}"
done

# Change extension
$ for f in *.jpeg; do
    mv "$f" "${f%.jpeg}.jpg"
done
```

### Using rename Command

```bash
# Perl rename (more powerful)
$ rename 's/.txt/.md/' *.txt

# Lowercase all filenames
$ rename 'y/A-Z/a-z/' *

# Replace spaces with underscores
$ rename 's/ /_/g' *

# Add prefix
$ rename 's/^/prefix_/' *.jpg

# Remove numbers from beginning
$ rename 's/^[0-9]+_//' *.mp3
```

### Using find

```bash
# Move all .log files older than 7 days
$ find . -name "*.log" -mtime +7 -exec mv {} /archive/ \;

# Move empty files
$ find . -type f -empty -exec mv {} /empty_files/ \;

# Move large files
$ find . -type f -size +100M -exec mv -v {} /large_files/ \;
```

## Moving Directories

```bash
# Move directory
$ mv old_directory/ /path/to/destination/

# Rename directory
$ mv old_name/ new_name/

# Move directory contents (not the directory itself)
$ mv old_directory/* new_directory/

# Move including hidden files
$ mv old_directory/{.,}* new_directory/
# Or use shopt
$ shopt -s dotglob
$ mv old_directory/* new_directory/
```

## Special Cases

### Files with Special Characters

```bash
# File starting with dash
$ mv -- -filename.txt normal_name.txt
$ mv ./-filename.txt normal_name.txt

# File with spaces
$ mv "file with spaces.txt" "new name.txt"
$ mv file\ with\ spaces.txt new_name.txt

# File with special characters
$ mv 'file[1].txt' 'file_1.txt'
```

### Cross-Filesystem Moves

```bash
# Moving across filesystems (actually copies then deletes)
$ mv /home/user/file.txt /mnt/external/
# This is slower than same-filesystem moves

# For large files, consider rsync with delete
$ rsync -av --remove-source-files file.txt /mnt/external/
```

### Atomic Operations

```bash
# mv is atomic on same filesystem
# Useful for safe file updates:
$ cp config.txt config.txt.new
$ # ... modify config.txt.new ...
$ mv config.txt.new config.txt  # Atomic replacement
```

## Common Patterns

### Organize Files by Extension

```bash
# Move files to folders by extension
$ for ext in jpg png gif; do
    mkdir -p images/$ext
    mv *.$ext images/$ext/ 2>/dev/null
done
```

### Archive Old Files

```bash
# Move files older than 30 days
$ find . -maxdepth 1 -type f -mtime +30 -exec mv {} archive/ \;
```

### Undo Moves (with backup)

```bash
# Always create backups
$ mv -b important.txt /new/location/
# If needed, restore from important.txt~
```

### Safe Script Pattern

```bash
#!/bin/bash
# Safe move with checks
src="$1"
dest="$2"

if [[ ! -e "$src" ]]; then
    echo "Source doesn't exist: $src"
    exit 1
fi

if [[ -e "$dest" ]]; then
    echo "Destination exists: $dest"
    read -p "Overwrite? (y/n) " -n 1 -r
    echo
    [[ $REPLY =~ ^[Yy]$ ]] || exit 1
fi

mv -v "$src" "$dest"
```

---

## mv vs cp + rm

| Aspect | `mv` | `cp` + `rm` |
|--------|------|-------------|
| Same filesystem | Instant (rename) | Slow (copy data) |
| Cross filesystem | Copy + delete | Copy + delete |
| Atomic | Yes (same fs) | No |
| Preserves inode | Yes (same fs) | No |

---

## Error Handling

```bash
# Check if move succeeded
if mv source.txt destination.txt; then
    echo "Move successful"
else
    echo "Move failed"
fi

# Move with error handling
$ mv file.txt /readonly_dir/
mv: cannot move 'file.txt' to '/readonly_dir/file.txt': Permission denied
```

---

> **Pro Tip:** Use `mv -i` in interactive shells to prevent accidental overwrites. Add `alias mv='mv -i'` to your `.bashrc` for safety.
