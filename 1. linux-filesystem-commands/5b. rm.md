# rm - Remove Files

The `rm` (remove) command is the standard tool for deleting files and directories. Unlike `rmdir`, which only handles empty folders, `rm` is designed for permanent data removal.

---

## Basic Usage

```bash
# Remove a single file
rm filename.txt

# Remove multiple files
rm file1.txt file2.jpg file3.pdf
```

---

## Common Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-i` | `--interactive` | Prompt before every removal |
| `-I` | | Prompt once before removing >3 files or recursively |
| `-r` | `--recursive` | Remove directories and their contents |
| `-f` | `--force` | Ignore nonexistent files, never prompt |
| `-v` | `--verbose` | Explain what is being done |
| `-d` | `--dir` | Remove empty directories |
| | `--preserve-root` | Do not remove '/' (default) |
| | `--no-preserve-root` | Do not treat '/' specially (DANGEROUS) |

## Examples & Demos

### Basic Removal

```bash
# Remove a single file
$ rm filename.txt

# Remove multiple files
$ rm file1.txt file2.jpg file3.pdf

# Remove all .tmp files
$ rm *.tmp

# Remove all files starting with "test_"
$ rm test_*
```

### Interactive Mode

```bash
# Prompt before each file
$ rm -i important_file.txt
rm: remove regular file 'important_file.txt'? y

# Prompt interactively for each file
$ rm -i *.log
rm: remove regular file 'app.log'? y
rm: remove regular file 'error.log'? n
rm: remove regular file 'debug.log'? y

# Prompt once for multiple files (safer than -i for many files)
$ rm -I *.log
rm: remove 15 arguments? y
```

### Directory Removal

```bash
# Remove directory and all contents
$ rm -r old_project/

# Remove with verbose output
$ rm -rv old_folder/
removed 'old_folder/file1.txt'
removed 'old_folder/file2.txt'
removed 'old_folder/subdir/data.txt'
removed directory 'old_folder/subdir/'
removed directory 'old_folder/'

# Remove empty directory only
$ rm -d empty_folder/
```

### Force Removal

```bash
# Force remove (no prompts, ignore nonexistent files)
$ rm -f nonexistent_file.txt
# No error even if file doesn't exist

# Force remove directory and contents (USE WITH CAUTION)
$ rm -rf temp_build/

# Force remove with verbose
$ rm -rfv cache/
```

### Pattern Matching

```bash
# Remove by extension
$ rm *.tmp
$ rm *.bak
$ rm *.log

# Remove by prefix
$ rm test_*
$ rm backup_*

# Remove by pattern
$ rm *_old.*
$ rm *.2025*

# Using find for complex patterns
$ find . -name "*.tmp" -exec rm {} \;
$ find . -type f -name "*.log" -mtime +30 -delete
```

### Advanced Usage

```bash
# Remove all except certain files (using extglob)
$ shopt -s extglob
$ rm !(keep_this.txt|also_keep.txt)

# Remove all except one pattern
$ rm !(*.txt)  # Removes everything except .txt files

# Safe recursive delete with confirmation
$ rm -riv project_backup/

# Remove files with special characters in names
$ rm -- -filename  # File starting with dash
$ rm './-filename'  # Alternative method
$ rm "file with spaces.txt"
$ rm file\ with\ spaces.txt
```

### Combining Flags

```bash
# Interactive + verbose
$ rm -iv *.bak
rm: remove regular file 'backup1.bak'? y
removed 'backup1.bak'
rm: remove regular file 'backup2.bak'? n

# Recursive + force + verbose
$ rm -rfv old_builds/

# Recursive + interactive (for each item)
$ rm -ri important_data/
```

## Critical Safety Warnings

| Warning | Description |
|---------|-------------|
| **Irreversibility** | Linux has no "Recycle Bin" for terminal deletions. Once removed, files are generally unrecoverable. |
| **Wildcard Danger** | Be extremely careful with `rm *`. Running this in the wrong directory wipes everything. |
| **The Nuclear Option** | NEVER run `rm -rf /` - this attempts to delete your entire filesystem. |
| **Sudo Caution** | `sudo rm -rf` is even more dangerous as it bypasses permission protections. |

---

## Safe Alternatives

### Using trash-cli

```bash
# Install trash-cli
$ sudo apt install trash-cli  # Debian/Ubuntu
$ sudo dnf install trash-cli  # Fedora

# Move to trash instead of delete
$ trash-put filename.txt

# View trash
$ trash-list

# Restore from trash
$ trash-restore

# Empty trash
$ trash-empty
```

### Creating Safe Aliases

Add to `~/.bashrc`:
```bash
# Always ask before removing
alias rm='rm -i'

# Or use trash instead
alias rm='trash-put'

# Safe recursive delete
alias rmr='rm -riv'
```

---

## rm vs rmdir

| Feature | `rm` | `rmdir` |
|---------|------|---------|
| Remove files | Yes | No |
| Remove empty directories | Yes (`-d`) | Yes |
| Remove non-empty directories | Yes (`-r`) | No |
| Safety level | Low | High |
| Force option | Yes (`-f`) | No |

---

> **Pro Tip:** Before using `rm -rf`, first use `ls` with the same pattern to preview what will be deleted: `ls -la path/to/delete/*`
