# mkdir - Make Directory

The `mkdir` (make directory) command creates new directories in the filesystem.

---

## Basic Usage

```bash
# Create a single directory
mkdir dirname

# Create multiple directories
mkdir dir1 dir2 dir3
```

---

## Common Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-p` | `--parents` | Create parent directories as needed; no error if exists |
| `-m` | `--mode=MODE` | Set file permissions (like chmod) |
| `-v` | `--verbose` | Print message for each created directory |
| `-Z` | | Set SELinux security context to default |
| | `--help` | Display help information |
| | `--version` | Show version information |

---

## Examples & Demos

### Basic Directory Creation

```bash
# Create a single directory
$ mkdir projects

# Create multiple directories
$ mkdir dir1 dir2 dir3
```

### Nested Directories

```bash
# Create nested directories (parent directories created automatically)
$ mkdir -p photos/2026/summer/vacation
# Creates: photos/, photos/2026/, photos/2026/summer/, photos/2026/summer/vacation/

# Without -p, this would fail if parents don't exist
$ mkdir deep/nested/path
mkdir: cannot create directory 'deep/nested/path': No such file or directory

# With -p, no error even if directory exists
$ mkdir -p existing_directory
# No error, silent success
```

### Verbose Output

```bash
# Create with verbose output
$ mkdir -v new_folder
mkdir: created directory 'new_folder'

# Create nested with verbose
$ mkdir -pv project/src/components
mkdir: created directory 'project'
mkdir: created directory 'project/src'
mkdir: created directory 'project/src/components'
```

### Setting Permissions

```bash
# Create with specific permissions (rwxr-xr-x = 755)
$ mkdir -m 755 public_folder

# Create private directory (rwx------ = 700)
$ mkdir -m 700 private_folder

# Create read-only directory for others (rwxr--r-- = 744)
$ mkdir -m 744 shared_folder

# Create with no permissions for others
$ mkdir -m 770 team_folder

# Combine flags: create nested directories with permissions and verbose
$ mkdir -pvm 755 webapp/public/assets/images
mkdir: created directory 'webapp'
mkdir: created directory 'webapp/public'
mkdir: created directory 'webapp/public/assets'
mkdir: created directory 'webapp/public/assets/images'
```

### Brace Expansion

```bash
# Create multiple directories with brace expansion
$ mkdir -p project/{src,docs,tests,build}
# Creates: project/src/, project/docs/, project/tests/, project/build/

# Complex structure with brace expansion
$ mkdir -p app/{frontend/{css,js,images},backend/{controllers,models,views}}
# Creates:
# app/frontend/css/
# app/frontend/js/
# app/frontend/images/
# app/backend/controllers/
# app/backend/models/
# app/backend/views/

# Numbered directories
$ mkdir -p data/day_{01..07}
# Creates: data/day_01/ through data/day_07/

# Multiple levels with multiple options
$ mkdir -p project/{src/{main,test},docs/{api,guides},config}
```

### Real-World Project Structures

```bash
# Web project structure
$ mkdir -pv mysite/{public/{css,js,images},src/{components,pages,utils},tests}

# Python project structure
$ mkdir -pv mypackage/{mypackage/{utils,models},tests,docs}

# Node.js project structure
$ mkdir -pv app/{src/{routes,controllers,models,middleware},tests/{unit,integration},config}

# Go project structure
$ mkdir -pv myapp/{cmd/myapp,internal/{handlers,models,services},pkg,api}
```

## Permission Reference

| Mode | Permissions | Description |
|------|-------------|-------------|
| `700` | `rwx------` | Owner only |
| `755` | `rwxr-xr-x` | Owner full, others read/execute |
| `775` | `rwxrwxr-x` | Owner/group full, others read/execute |
| `777` | `rwxrwxrwx` | Everyone full access |
| `750` | `rwxr-x---` | Owner full, group read/execute |

---

> **Pro Tip:** Always use `-p` when scripting to prevent errors if directories already exist.
