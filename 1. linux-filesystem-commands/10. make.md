# make - Build Automation Tool

While `touch` or `echo` create individual files, `make` is a high-level automation tool used to manage groups of files that depend on each other. It reads instructions from a file named `Makefile`.

---

## How It Works

A Makefile consists of "rules" with this structure:

```makefile
target: dependencies
	command
```

- **Target**: The file to create (e.g., an executable)
- **Dependencies**: Files needed to create the target
- **Command**: The terminal command to run (MUST use Tab, not spaces)

**Key Feature**: `make` checks timestamps. If a dependency is newer than the target, only then does it rebuild.

---

## Common Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-f FILE` | `--file=FILE` | Use FILE as the makefile |
| `-n` | `--just-print` | Dry run - print commands without executing |
| `-j N` | `--jobs=N` | Run N jobs in parallel |
| `-k` | `--keep-going` | Continue after errors |
| `-s` | `--silent` | Don't print commands |
| `-B` | `--always-make` | Rebuild all targets |
| `-C DIR` | `--directory=DIR` | Change to DIR before running |
| `-d` | `--debug` | Print debugging information |
| `-p` | | Print the make database |
| `-W FILE` | `--what-if=FILE` | Pretend FILE was modified |
| `-i` | `--ignore-errors` | Ignore errors from commands |

---

## Common Targets

| Target | Description |
|--------|-------------|
| `all` | Build the entire project (often default) |
| `clean` | Remove compiled files |
| `install` | Install to system directories |
| `uninstall` | Remove installed files |
| `test` | Run tests |
| `dist` | Create distribution package |
| `help` | Show available targets |
| `.PHONY` | Declare targets that aren't files |

## Examples & Demos

### Command Line Usage

```bash
# Build default target (usually 'all')
$ make

# Build specific target
$ make clean
$ make install
$ make test

# Dry run - see what would happen
$ make -n

# Parallel build (4 jobs)
$ make -j4

# Maximum parallel (number of CPU cores)
$ make -j$(nproc)

# Silent mode (don't print commands)
$ make -s

# Use different makefile
$ make -f Makefile.debug

# Build from different directory
$ make -C src/

# Rebuild everything regardless of timestamps
$ make -B

# Continue after errors
$ make -k

# Pass variables on command line
$ make CC=clang CFLAGS="-O2"

# Show make database (debugging)
$ make -p

# Verbose output
$ make VERBOSE=1
```

### Basic Makefile

```makefile
# Compiler settings
CC = gcc
CFLAGS = -Wall -g

# Default target
all: program

# Link object files
program: main.o utils.o
	$(CC) $(CFLAGS) -o program main.o utils.o

# Compile source files
main.o: main.c
	$(CC) $(CFLAGS) -c main.c

utils.o: utils.c utils.h
	$(CC) $(CFLAGS) -c utils.c

# Clean up
clean:
	rm -f *.o program

# Phony targets (not real files)
.PHONY: all clean
```

## Variables

```makefile
# Simple assignment
CC = gcc
CFLAGS = -Wall -g

# Recursive (expanded when used)
FILES = $(wildcard *.c)

# Simple (expanded immediately)
FILES := $(wildcard *.c)

# Conditional (set only if not already set)
CC ?= gcc

# Append
CFLAGS += -O2

# Use variables
program: $(SRCS)
	$(CC) $(CFLAGS) -o $@ $^
```

### Common Variables

| Variable | Description |
|----------|-------------|
| `CC` | C compiler |
| `CXX` | C++ compiler |
| `CFLAGS` | C compiler flags |
| `CXXFLAGS` | C++ compiler flags |
| `LDFLAGS` | Linker flags |
| `LDLIBS` | Libraries to link |

---

## Automatic Variables

| Variable | Description |
|----------|-------------|
| `$@` | Target name |
| `$^` | All dependencies |
| `$<` | First dependency |
| `$?` | Dependencies newer than target |
| `$*` | Stem (matched by %) |
| `$(@D)` | Directory part of target |
| `$(@F)` | File part of target |

```makefile
# Example using automatic variables
program: main.o utils.o
	$(CC) -o $@ $^
# $@ = program
# $^ = main.o utils.o

%.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@
# $< = the .c file
# $@ = the .o file
```

---

## Pattern Rules

```makefile
# Generic rule: any .o from any .c
%.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@

# Any .o from matching .cpp
%.o: %.cpp
	$(CXX) $(CXXFLAGS) -c $< -o $@
```

---

## Functions

```makefile
# Wildcard - get all matching files
SRCS = $(wildcard src/*.c)

# Substitution - change extension
OBJS = $(SRCS:.c=.o)
# Or using patsubst
OBJS = $(patsubst %.c,%.o,$(SRCS))

# Add prefix/suffix
HEADERS = $(addprefix include/,$(MODULES))
OBJECTS = $(addsuffix .o,$(MODULES))

# Filter
C_FILES = $(filter %.c,$(SRCS))
NOT_MAIN = $(filter-out main.c,$(SRCS))

# Shell command
DATE = $(shell date +%Y%m%d)
```

---

## Conditionals

```makefile
# Check if variable is set
DEBUG ?= 0

ifeq ($(DEBUG), 1)
    CFLAGS += -DDEBUG -g
else
    CFLAGS += -O2
endif

# Check if variable is defined
ifdef VERBOSE
    Q =
else
    Q = @
endif

# Check if command exists
ifeq ($(shell which clang 2>/dev/null),)
    CC = gcc
else
    CC = clang
endif
```

## Complete Makefile Examples

### C Project

```makefile
# Compiler and flags
CC = gcc
CFLAGS = -Wall -Wextra -g
LDFLAGS = -lm

# Directories
SRCDIR = src
OBJDIR = obj
BINDIR = bin

# Files
SRCS = $(wildcard $(SRCDIR)/*.c)
OBJS = $(patsubst $(SRCDIR)/%.c,$(OBJDIR)/%.o,$(SRCS))
TARGET = $(BINDIR)/program

# Default target
all: directories $(TARGET)

# Create directories
directories:
	@mkdir -p $(OBJDIR) $(BINDIR)

# Link
$(TARGET): $(OBJS)
	$(CC) $(OBJS) -o $@ $(LDFLAGS)

# Compile
$(OBJDIR)/%.o: $(SRCDIR)/%.c
	$(CC) $(CFLAGS) -c $< -o $@

# Clean
clean:
	rm -rf $(OBJDIR) $(BINDIR)

# Install
install: $(TARGET)
	cp $(TARGET) /usr/local/bin/

# Help
help:
	@echo "Targets:"
	@echo "  all      - Build the program"
	@echo "  clean    - Remove build files"
	@echo "  install  - Install to /usr/local/bin"

.PHONY: all clean install help directories
```

### Python Project

```makefile
PYTHON = python3
VENV = venv
PIP = $(VENV)/bin/pip
PYTEST = $(VENV)/bin/pytest

.PHONY: all venv install test clean lint

all: venv install

venv:
	$(PYTHON) -m venv $(VENV)

install: venv
	$(PIP) install -r requirements.txt

test:
	$(PYTEST) tests/

lint:
	$(VENV)/bin/flake8 src/

clean:
	rm -rf $(VENV)
	find . -type d -name __pycache__ -exec rm -rf {} +
	find . -type f -name "*.pyc" -delete
```

### Node.js Project

```makefile
NPM = npm
NODE_MODULES = node_modules

.PHONY: all install dev build test clean

all: install build

install: $(NODE_MODULES)

$(NODE_MODULES): package.json
	$(NPM) install
	touch $(NODE_MODULES)

dev:
	$(NPM) run dev

build: install
	$(NPM) run build

test: install
	$(NPM) test

clean:
	rm -rf $(NODE_MODULES) dist
```
