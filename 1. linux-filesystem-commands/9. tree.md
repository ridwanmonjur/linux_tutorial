# tree - Display Directory Tree Structure

The `tree` command displays the contents of a directory in a tree-like format, showing the hierarchical structure of files and subdirectories. It's an excellent tool for understanding project layouts and documenting directory structures.

---

## Installation

`tree` is not always installed by default:

```bash
# Debian/Ubuntu
sudo apt install tree

# RHEL/CentOS/Fedora
sudo dnf install tree

# Arch Linux
sudo pacman -S tree

# macOS (with Homebrew)
brew install tree
```

---

## Basic Usage

```bash
# Display tree of current directory
tree

# Display tree of specific directory
tree /path/to/directory

# Display tree of multiple directories
tree dir1 dir2 dir3
```

**Example Output:**
```
.
├── docs
│   ├── api.md
│   └── guide.md
├── src
│   ├── main.c
│   └── utils.c
├── Makefile
└── README.md

2 directories, 6 files
```

## Common Flags

### Display Control

| Flag | Description |
|------|-------------|
| `-a` | Show all files including hidden (starting with `.`) |
| `-d` | List directories only |
| `-f` | Print full path prefix for each file |
| `-i` | Don't print indentation lines |
| `-l` | Follow symbolic links |
| `-x` | Stay on current filesystem only |

### Depth Control

| Flag | Description |
|------|-------------|
| `-L level` | Limit display to `level` directories deep |
| `--filelimit #` | Skip directories with more than # entries |

### Filtering

| Flag | Description |
|------|-------------|
| `-I pattern` | Exclude files matching pattern (supports wildcards) |
| `-P pattern` | Include only files matching pattern |
| `--matchdirs` | Apply patterns to directory names too |
| `--prune` | Remove empty directories from output |

### Sorting

| Flag | Description |
|------|-------------|
| `-t` | Sort by modification time |
| `-c` | Sort by change time |
| `-r` | Reverse sort order |
| `-v` | Sort by version (natural sort) |
| `-U` | No sorting (order as stored) |
| `--dirsfirst` | List directories before files |

### File Information

| Flag | Description |
|------|-------------|
| `-s` | Print file size in bytes |
| `-h` | Print human-readable sizes (with `-s`) |
| `-D` | Print last modification date |
| `-p` | Print file permissions |
| `-u` | Print username/uid |
| `-g` | Print group name/gid |
| `--inodes` | Print inode numbers |

### Output Format

| Flag | Description |
|------|-------------|
| `-n` | No color (always) |
| `-C` | Colorize output (always) |
| `-J` | Output as JSON |
| `-X` | Output as XML |
| `-H baseHREF` | Output as HTML |
| `-o filename` | Write output to file |

## Examples & Demos

### Basic Tree Views

```bash
# Simple tree
$ tree
.
├── README.md
├── package.json
└── src
    ├── index.js
    └── utils.js

1 directory, 4 files

# Include hidden files
$ tree -a
.
├── .git
│   ├── config
│   └── HEAD
├── .gitignore
├── README.md
└── src
    └── index.js

# Directories only
$ tree -d
.
├── node_modules
├── public
└── src
    └── components

4 directories
```

### Depth Limiting

```bash
# Show only 1 level deep
$ tree -L 1
.
├── docs
├── node_modules
├── public
├── src
├── package.json
└── README.md

4 directories, 2 files

# Show 2 levels deep
$ tree -L 2
.
├── docs
│   ├── api.md
│   └── guide.md
├── src
│   ├── components
│   └── index.js
└── package.json

3 directories, 4 files

# Directories only, 2 levels
$ tree -dL 2
```

### Filtering Files

```bash
# Exclude node_modules and .git
$ tree -I 'node_modules|.git'

# Exclude multiple patterns
$ tree -I '*.pyc|__pycache__|.git|node_modules'

# Show only JavaScript files
$ tree -P '*.js'

# Show only Python files, don't prune empty dirs
$ tree -P '*.py' --prune

# Match directories too
$ tree -P 'test*' --matchdirs --prune
```

### File Information

```bash
# Show file sizes (bytes)
$ tree -s
.
├── [       4096]  docs
│   └── [       2048]  api.md
├── [       8192]  README.md
└── [       1024]  Makefile

# Human-readable sizes
$ tree -sh
.
├── [4.0K]  docs
│   └── [2.0K]  api.md
├── [8.0K]  README.md
└── [1.0K]  Makefile

# Show permissions
$ tree -p
.
├── [drwxr-xr-x]  docs
│   └── [-rw-r--r--]  api.md
├── [-rw-r--r--]  README.md
└── [-rw-r--r--]  Makefile

# Show dates
$ tree -D
.
├── [Jan 15 10:30]  docs
│   └── [Jan 14 09:00]  api.md
└── [Jan 10 14:22]  README.md

# Full details (size + permissions + date)
$ tree -pshD
```

### Sorting

```bash
# Sort by modification time (newest first)
$ tree -t

# Sort by time, oldest first
$ tree -tr

# Directories first
$ tree --dirsfirst

# Directories first with time sort
$ tree --dirsfirst -t

# No sorting (fastest for large directories)
$ tree -U
```

### Output Formats

```bash
# Save to file
$ tree -o project_structure.txt

# JSON output
$ tree -J
[{"type":"directory","name":".","contents":[
  {"type":"file","name":"README.md"},
  {"type":"directory","name":"src","contents":[
    {"type":"file","name":"index.js"}
  ]}
]}]

# JSON output to file
$ tree -J -o structure.json

# XML output
$ tree -X

# HTML output
$ tree -H "https://example.com/files" > files.html
```

### Full Path Display

```bash
# Show full path for each file
$ tree -f
.
├── ./README.md
├── ./src
│   ├── ./src/index.js
│   └── ./src/utils.js
└── ./package.json

# Full path without indentation lines
$ tree -fi
.
./README.md
./src
./src/index.js
./src/utils.js
./package.json
```

### Advanced Combinations

```bash
# Project overview: 2 levels, dirs first, exclude common junk
$ tree -L 2 --dirsfirst -I 'node_modules|.git|__pycache__|*.pyc'

# Detailed view for documentation
$ tree -pshD --dirsfirst

# Find all Python files with sizes
$ tree -P '*.py' --prune -sh

# Generate project README structure
$ tree -L 3 --dirsfirst -I 'node_modules|.git|dist|build' > STRUCTURE.md

# Count files by extension
$ tree -fi | grep -E '\.(js|ts)$' | wc -l

# Compare two directory structures
$ diff <(tree dir1 -nfi) <(tree dir2 -nfi)
```

## Use Cases

### Document Project Structure

```bash
# Add to README.md
echo '```' >> README.md
echo '## Project Structure' >> README.md
tree -L 3 --dirsfirst -I 'node_modules|.git' >> README.md
echo '```' >> README.md
```

### Quick Directory Overview

```bash
# See project layout at a glance
$ tree -L 2 -d
.
├── backend
│   ├── controllers
│   ├── models
│   └── routes
├── frontend
│   ├── components
│   ├── pages
│   └── styles
└── tests
    ├── integration
    └── unit

12 directories
```

### Finding Large Directories

```bash
# Show directory sizes
$ tree -d -h --du
.
├── [150M]  node_modules
├── [ 12M]  build
├── [2.5M]  src
└── [500K]  docs

4 directories, total: 165M
```

## Comparison with ls -R

| Feature | `tree` | `ls -R` |
|---------|--------|---------|
| Visual hierarchy | Yes (tree lines) | No (flat list) |
| Depth limiting | Yes (`-L`) | No |
| Pattern filtering | Yes (`-I`, `-P`) | No |
| Multiple output formats | Yes (JSON, XML, HTML) | No |
| Summary statistics | Yes (file/dir count) | No |
| Sorting options | Many | Limited |

---

> **Pro Tip:** Create an alias for common use: `alias t='tree -L 2 --dirsfirst -I "node_modules|.git|__pycache__"'`
