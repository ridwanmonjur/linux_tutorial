# File Searching - find, locate, and which

Learn to efficiently locate files and commands on your Linux system.

---

## Quick Comparison

| Command | Purpose | Speed | Database | Searches |
|---------|---------|-------|----------|----------|
| `find` | Real-time file search | Slower | None | Live filesystem |
| `locate` | Fast database search | Fast | Yes (updatedb) | Pre-built index |
| `which` | Find command location | Fast | None | PATH directories |
| `whereis` | Find binary/source/man | Fast | None | Standard locations |
| `type` | Identify command type | Fast | None | Shell builtins + PATH |

---

## find - Search Filesystem in Real-Time

The most powerful and flexible file search tool.

### Basic Syntax

```bash
find [path] [options] [expression]
```

### Search by Name

```bash
# Find by exact name
find /home -name "file.txt"

# Case insensitive
find /home -iname "file.txt"

# Using wildcards
find . -name "*.txt"
find . -name "test*"
find . -name "*config*"

# Find in current directory
find . -name "README.md"

# Find in multiple paths
find /usr /opt -name "python*"
```

### Search by Type

| Type | Description |
|------|-------------|
| `f` | Regular file |
| `d` | Directory |
| `l` | Symbolic link |
| `c` | Character device |
| `b` | Block device |
| `s` | Socket |
| `p` | Named pipe |

```bash
# Find only files
find . -type f -name "*.log"

# Find only directories
find . -type d -name "test*"

# Find symbolic links
find . -type l

# Find empty files
find . -type f -empty

# Find empty directories
find . -type d -empty
```

### Search by Size

| Suffix | Unit |
|--------|------|
| `c` | Bytes |
| `k` | Kilobytes |
| `M` | Megabytes |
| `G` | Gigabytes |

```bash
# Files larger than 100MB
find . -size +100M

# Files smaller than 10KB
find . -size -10k

# Files exactly 1GB
find . -size 1G

# Files between sizes
find . -size +10M -size -100M

# Find large files
find / -type f -size +500M 2>/dev/null
```

### Search by Time

| Option | Measures |
|--------|----------|
| `-mtime` | Modification time (content changed) |
| `-atime` | Access time (file read) |
| `-ctime` | Change time (metadata changed) |
| `-mmin` | Modification in minutes |
| `-amin` | Access in minutes |
| `-cmin` | Change in minutes |

```bash
# Modified in last 24 hours
find . -mtime -1

# Modified more than 7 days ago
find . -mtime +7

# Modified exactly 3 days ago
find . -mtime 3

# Modified in last 30 minutes
find . -mmin -30

# Accessed in last hour
find . -amin -60

# Files modified between 7 and 14 days ago
find . -mtime +7 -mtime -14

# Files newer than reference file
find . -newer reference.txt
```

### Search by Permissions

```bash
# Files with exact permissions
find . -perm 644

# Files with at least these permissions
find . -perm -644

# Files with any of these permissions
find . -perm /644

# World-writable files
find . -perm -002

# Executable files
find . -perm /111

# SUID files
find / -perm -4000 2>/dev/null

# SGID files
find / -perm -2000 2>/dev/null
```

### Search by Owner/Group

```bash
# Files owned by user
find . -user john

# Files owned by group
find . -group developers

# Files owned by UID
find . -uid 1000

# Files owned by GID
find . -gid 1000

# Files with no owner
find . -nouser

# Files with no group
find . -nogroup
```

### Combining Conditions

```bash
# AND (default)
find . -name "*.txt" -type f

# OR
find . -name "*.txt" -o -name "*.md"

# NOT
find . ! -name "*.txt"
find . -not -name "*.txt"

# Complex conditions with grouping
find . \( -name "*.txt" -o -name "*.md" \) -type f

# Multiple exclusions
find . -type f ! -name "*.log" ! -name "*.tmp"
```

### Limiting Depth

```bash
# Only current directory (no recursion)
find . -maxdepth 1 -name "*.txt"

# Up to 2 levels deep
find . -maxdepth 2 -type d

# At least 2 levels deep
find . -mindepth 2 -name "*.txt"
```

### Actions on Found Files

```bash
# Print (default)
find . -name "*.txt" -print

# Print with null separator (for xargs)
find . -name "*.txt" -print0

# Delete found files (CAREFUL!)
find . -name "*.tmp" -delete

# Execute command on each file
find . -name "*.txt" -exec cat {} \;

# Execute command on all files at once
find . -name "*.txt" -exec cat {} +

# Execute with confirmation
find . -name "*.txt" -ok rm {} \;

# Using xargs (more efficient)
find . -name "*.txt" | xargs grep "pattern"
find . -name "*.txt" -print0 | xargs -0 grep "pattern"
```

### Practical Examples

```bash
# Find and delete old log files
find /var/log -name "*.log" -mtime +30 -delete

# Find large files
find / -type f -size +100M -exec ls -lh {} \; 2>/dev/null

# Find modified config files
find /etc -name "*.conf" -mtime -7

# Find and fix permissions
find /var/www -type f -exec chmod 644 {} \;
find /var/www -type d -exec chmod 755 {} \;

# Find duplicate names
find . -name "config.yml"

# Find broken symlinks
find . -type l ! -exec test -e {} \; -print

# Find files by extension, excluding directories
find . -type f \( -name "*.js" -o -name "*.ts" \) ! -path "*/node_modules/*"

# Count files by extension
find . -type f -name "*.py" | wc -l

# Find recently modified source files
find ./src -name "*.js" -mmin -60

# Backup files modified today
find . -mtime -1 -type f -exec cp {} /backup/ \;
```

## locate - Fast Database Search

Uses a pre-built database for instant results.

### Basic Usage

```bash
# Search for files
locate filename

# Case insensitive
locate -i filename

# Show only existing files
locate -e filename

# Limit results
locate -n 10 pattern

# Count matches
locate -c pattern
```

### Update Database

```bash
# Update the database (requires root)
sudo updatedb

# Update is usually scheduled via cron
# Check: /etc/cron.daily/locate or mlocate
```

### Examples

```bash
# Find all Python files
locate "*.py"

# Find config files
locate ".conf"

# Case insensitive search
locate -i readme

# Find and filter with grep
locate ".log" | grep /var/

# Count PHP files
locate -c "*.php"
```

### Limitations

- Database may be outdated (updated daily by default)
- Doesn't search file contents
- May not find recently created files
- Respects file permissions (won't show files you can't access)

## which - Find Command Location

Locates executable commands in your PATH.

### Basic Usage

```bash
# Find command location
which python
which python3

# Find all matches (not just first)
which -a python

# Check multiple commands
which python pip node
```

### Examples

```bash
$ which bash
/usr/bin/bash

$ which python python3
/usr/bin/python
/usr/bin/python3

$ which -a python
/usr/bin/python
/usr/local/bin/python
```

## whereis - Find Binary, Source, Manual

Searches standard system directories for binaries, source code, and man pages.

### Basic Usage

```bash
# Find all (binary, source, man)
whereis python

# Binary only
whereis -b python

# Manual pages only
whereis -m python

# Source only
whereis -s python
```

### Examples

```bash
$ whereis bash
bash: /usr/bin/bash /usr/share/man/man1/bash.1.gz

$ whereis -b python
python: /usr/bin/python

$ whereis -m ls
ls: /usr/share/man/man1/ls.1.gz
```

## type - Identify Command Type

Shows how a command would be interpreted by the shell.

### Basic Usage

```bash
# Show command type
type command

# Show all locations
type -a command

# Just the type (alias, builtin, file, function, keyword)
type -t command
```

### Examples

```bash
$ type cd
cd is a shell builtin

$ type ls
ls is aliased to 'ls --color=auto'

$ type python
python is /usr/bin/python

$ type -a echo
echo is a shell builtin
echo is /usr/bin/echo

$ type -t grep
file

$ type -t cd
builtin
```

### Command Types

| Type | Description |
|------|-------------|
| alias | Shell alias |
| builtin | Shell built-in command |
| file | External executable |
| function | Shell function |
| keyword | Shell reserved word |

## Comparison Summary

### When to Use Each

| Scenario | Best Tool |
|----------|-----------|
| Find files by name (exact path unknown) | `find` or `locate` |
| Need current/real-time results | `find` |
| Quick search, okay if slightly outdated | `locate` |
| Find where a command lives | `which` |
| Find binary and its man page | `whereis` |
| Check if command is alias/builtin/file | `type` |
| Complex search criteria | `find` |
| Search by size/date/permissions | `find` |
| Simple name search across system | `locate` |

### Speed Comparison

```bash
# locate is faster for simple searches
time locate "*.conf" | wc -l
# real: 0.1s

time find / -name "*.conf" 2>/dev/null | wc -l
# real: 30s+
```

## Pro Tips

```bash
# Exclude directories in find
find . -name "*.js" -not -path "./node_modules/*"

# Combine find with grep for content search
find . -name "*.py" -exec grep -l "import os" {} \;

# Use fd (modern find alternative) if available
fd "*.txt"

# Use fzf for interactive file finding
find . -type f | fzf
```
