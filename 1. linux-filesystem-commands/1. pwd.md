# pwd - Print Working Directory

The `pwd` command stands for **Print Working Directory**. It is one of the most basic tools used in Linux, Unix, and macOS terminals to tell you exactly where you are in the filesystem.

---

## What It Does

When you type `pwd` and press Enter, the terminal displays the absolute path (the full address starting from the root `/`) of the folder you are currently "standing" in.

---

## Basic Usage

```bash
pwd
```

**Example Output:**
```
/home/username/Documents
```

---

## Flags

| Flag | Description |
|------|-------------|
| `-L` | Display the logical path (follows symlinks) - **default** |
| `-P` | Display the physical path (resolves symlinks) |

---

## Examples & Demos

```bash
# Basic usage - show current directory
$ pwd
/home/user/projects

# Show logical path (default behavior)
$ pwd -L
/home/user/projects

# Show physical path (resolves symbolic links)
$ cd /var/log
$ pwd -P
/var/log

# Demonstrate symlink difference
$ ln -s /home/user/projects ~/mylink
$ cd ~/mylink
$ pwd -L
/home/user/mylink
$ pwd -P
/home/user/projects
```

---

## Use Cases

### Finding Your Location
If you've been navigating with `cd`, it's easy to lose track of where you are:
```bash
$ cd /etc
$ cd ../var
$ cd log
$ pwd
/var/log
```

### Scripting
Capture current directory in scripts:
```bash
#!/bin/bash
CURRENT_DIR=$(pwd)
echo "Script running from: $CURRENT_DIR"
```

### Symlink Debugging
Check if you're in a symlink or real directory:
```bash
$ pwd -L   # Shows symlink path
$ pwd -P   # Shows actual path
```

---

> **Pro Tip:** `pwd` acts like a "You Are Here" marker on a map when you're lost in the filesystem.
