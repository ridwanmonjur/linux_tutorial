# nano - Terminal Text Editor

Nano is a "modeless" text editor, meaning you can start typing the moment you open a file without switching between modes like in Vim. Its keyboard shortcuts are always visible at the bottom of the screen.

---

## Basic Usage

```bash
# Open or create a file
nano filename.txt

# Open at specific line number
nano +50 largefile.txt

# Open at specific line and column
nano +50,10 file.txt
```

---

## Essential Keyboard Shortcuts

In Nano's interface, `^` represents `Ctrl` and `M-` represents `Alt`.

### File Operations

| Shortcut | Action |
|----------|--------|
| `Ctrl + O` | Save file (Write Out) |
| `Ctrl + X` | Exit nano |
| `Ctrl + R` | Insert another file at cursor position |
| `Ctrl + S` | Save file (alternative) |

### Editing

| Shortcut | Action |
|----------|--------|
| `Ctrl + K` | Cut current line |
| `Ctrl + U` | Paste (Uncut) |
| `Alt + 6` | Copy current line |
| `Ctrl + J` | Justify paragraph |
| `Ctrl + \` | Find and replace |
| `Alt + U` | Undo |
| `Alt + E` | Redo |
| `Ctrl + ^` | Mark text start (then move cursor to select) |

### Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl + W` | Search (Where Is) |
| `Ctrl + _` | Go to line number |
| `Ctrl + A` | Move to beginning of line |
| `Ctrl + E` | Move to end of line |
| `Ctrl + Y` | Page up |
| `Ctrl + V` | Page down |
| `Alt + \` | Go to beginning of file |
| `Alt + /` | Go to end of file |
| `Ctrl + C` | Show cursor position |

### Selection & Copying

| Shortcut | Action |
|----------|--------|
| `Alt + A` | Start/stop marking text |
| `Ctrl + K` | Cut marked text |
| `Alt + 6` | Copy marked text |
| `Ctrl + U` | Paste text |

## Command Line Flags

### Display Options

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-l` | `--linenumbers` | Show line numbers |
| `-c` | `--constantshow` | Constantly show cursor position |
| `-S` | `--softwrap` | Enable soft wrapping |
| `-$` | `--softwrap` | Same as -S |
| `-w` | `--nowrap` | Don't wrap long lines |
| `-m` | `--mouse` | Enable mouse support |
| `-x` | `--nohelp` | Don't show help bar at bottom |

### File Handling

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-B` | `--backup` | Create backup file before saving |
| `-C dir` | `--backupdir=dir` | Directory for backup files |
| `-v` | `--view` | View mode (read-only) |
| `-L` | `--nonewlines` | Don't add newline at end of file |
| `-N` | `--noconvert` | Don't convert from DOS/Mac format |

### Editing Behavior

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-i` | `--autoindent` | Auto-indent new lines |
| `-E` | `--tabstospaces` | Convert tabs to spaces |
| `-T n` | `--tabsize=n` | Set tab size to n columns |
| `-a` | `--atblanks` | Wrap at whitespace |

### Syntax Highlighting

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-Y syntax` | `--syntax=syntax` | Use specific syntax highlighting |

## Examples & Demos

### Opening Files

```bash
# Open or create a file
$ nano filename.txt

# Open with line numbers displayed
$ nano -l script.sh

# Open at specific line number
$ nano +50 largefile.txt

# Open in read-only mode
$ nano -v important_config.conf

# Open with mouse support
$ nano -m document.txt
```

### Backup Options

```bash
# Open with backup (creates filename.txt~)
$ nano -B config.ini

# Specify backup directory
$ nano -B -C ~/backups config.txt
```

### Editing Options

```bash
# Open with auto-indent and convert tabs to spaces
$ nano -iE code.py

# Set tab size to 4 spaces
$ nano -T 4 Makefile

# Open with soft wrapping enabled
$ nano -S long_lines.txt

# No word wrap (for code)
$ nano -w script.sh
```

### Syntax Highlighting

```bash
# Open with specific syntax highlighting
$ nano -Y python script.py
$ nano -Y sh script.sh
$ nano -Y html index.html
$ nano -Y c program.c
```

### Combined Options

```bash
# Multiple options combined
$ nano -liT4 -B main.c
# -l: line numbers
# -i: auto-indent
# -T4: tab size 4
# -B: create backup

# Ideal for code editing
$ nano -lmiET4 -Y python app.py
```

## Configuration (~/.nanorc)

Create or edit `~/.nanorc` to set permanent preferences:

```bash
# Enable line numbers
set linenumbers

# Enable mouse
set mouse

# Set tab size
set tabsize 4

# Convert tabs to spaces
set tabstospaces

# Enable soft wrapping
set softwrap

# Enable auto-indent
set autoindent

# Show cursor position constantly
set constantshow

# Enable syntax highlighting
include "/usr/share/nano/*.nanorc"

# Or include specific languages
include "/usr/share/nano/python.nanorc"
include "/usr/share/nano/sh.nanorc"
include "/usr/share/nano/javascript.nanorc"

# Custom colors
set titlecolor brightwhite,blue
set statuscolor brightwhite,green
set keycolor cyan
set functioncolor yellow
```

### Color Options

```bash
# In ~/.nanorc
set titlecolor brightwhite,blue
set statuscolor brightwhite,green
set errorcolor brightwhite,red
set selectedcolor brightwhite,magenta
set numbercolor cyan
set keycolor cyan
set functioncolor yellow
```

## Practical Examples

### Quick Config Edit

```bash
# Edit with backup
$ sudo nano -B /etc/hosts
```

### Code Editing

```bash
# Python with all the bells and whistles
$ nano -lmiET4 -Y python script.py
```

### Log Viewing

```bash
# Read-only view of log
$ nano -v /var/log/syslog
```

### Quick Notes

```bash
# Create quick note with line numbers
$ nano -l ~/notes/$(date +%Y-%m-%d).txt
```
