# cat - Concatenate & Display Files

The `cat` (concatenate) command is one of the most versatile tools in Linux. While commonly used for reading files, its true power lies in combining, creating, and manipulating text streams.

---

## Basic Usage

```bash
# Display file contents
cat filename.txt

# Display multiple files
cat file1.txt file2.txt

# Display with stdin
cat
```

---

## Common Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-n` | `--number` | Number all output lines |
| `-b` | `--number-nonblank` | Number non-empty output lines only |
| `-s` | `--squeeze-blank` | Suppress repeated empty lines |
| `-E` | `--show-ends` | Display $ at end of each line |
| `-T` | `--show-tabs` | Display TAB characters as ^I |
| `-A` | `--show-all` | Equivalent to -vET |
| `-v` | `--show-nonprinting` | Show non-printing characters |
| `-e` | | Equivalent to -vE |
| `-t` | | Equivalent to -vT |

## Examples & Demos

### Reading Files

```bash
# Display file contents
$ cat filename.txt
Hello World
This is a test file.

# Display multiple files (concatenated)
$ cat file1.txt file2.txt file3.txt

# Display with line numbers
$ cat -n script.sh
     1	#!/bin/bash
     2	echo "Hello World"
     3
     4	exit 0

# Number only non-blank lines
$ cat -b script.sh
     1	#!/bin/bash
     2	echo "Hello World"

     3	exit 0
```

### Formatting Output

```bash
# Squeeze multiple blank lines into one
$ cat -s messy_file.txt

# Show hidden characters (tabs, line endings)
$ cat -A config.txt
server_name^Ilocalhost$
port^I8080$

# Show only line endings
$ cat -E file.txt
Hello World$
Another line$

# Show only tabs
$ cat -T Makefile
target:^Idependencies
^Icommand
```

### Creating Files

```bash
# Create a file and type content (Ctrl+D to save)
$ cat > newfile.txt
This is line 1
This is line 2
^D

# Append to existing file
$ cat >> existing.txt
Adding more content
^D
```

### Using Heredoc

```bash
# Create file with heredoc
$ cat > config.txt << EOF
server=localhost
port=8080
debug=true
EOF

# Append with heredoc
$ cat >> config.txt << EOF
timeout=30
retries=3
EOF

# Heredoc with variable substitution
$ cat > greeting.txt << EOF
Hello $USER
Today is $(date)
EOF

# Heredoc without variable substitution (quoted EOF)
$ cat > literal.txt << 'EOF'
Hello $USER
This stays literal: $(date)
EOF
```

### Combining Files

```bash
# Merge files into a new file
$ cat header.txt body.txt footer.txt > complete.html

# Append one file to another
$ cat additional.txt >> main.txt

# Combine with stdin (- represents stdin)
$ echo "Header Line" | cat - datafile.txt > output.txt

# Number lines while combining
$ cat -n file1.txt file2.txt > numbered_output.txt

# Combine all .txt files
$ cat *.txt > combined.txt
```

### Viewing Binary Files Safely

```bash
# Display binary file safely (shows non-printable chars)
$ cat -v binary_file

# If terminal gets messed up after viewing binary
$ reset
```

### Reverse Display (tac)

```bash
# Display file in reverse line order
$ tac filename.txt

# Reverse and number
$ tac filename.txt | cat -n
```

## Practical Use Cases

### Quick File Preview

```bash
# View short config file
$ cat /etc/hostname

# View multiple configs
$ cat /etc/hosts /etc/resolv.conf
```

### Debugging Whitespace

```bash
# Check for trailing spaces or wrong line endings
$ cat -A problematic_file.txt
Line with trailing spaces   $
Line with tab^Icharacter$
```

### Creating Scripts

```bash
# Quick script creation
$ cat > backup.sh << 'EOF'
#!/bin/bash
tar -czf backup_$(date +%Y%m%d).tar.gz ~/Documents
echo "Backup complete"
EOF
$ chmod +x backup.sh
```

### Combining Log Files

```bash
# Merge logs chronologically
$ cat access.log.1 access.log > all_access.log

# Combine with header
$ echo "=== Combined Logs ===" | cat - *.log > combined.log
```

## Related Commands

| `more` | Simple pagination |
| `nl` | Number lines (more options than `cat -n`) |

---

## When NOT to Use cat

```bash
# Useless use of cat (UUOC)
$ cat file.txt | grep pattern    # Bad
$ grep pattern file.txt          # Good

$ cat file.txt | wc -l           # Bad
$ wc -l < file.txt               # Good

# For large files, use less instead
$ less large_file.log            # Better than cat
```

---

> **Pro Tip:** For large files, use `less` or `head`/`tail` instead of `cat` to avoid flooding your terminal.
