# touch - Create Files & Modify Timestamps

While most people use `touch` to create empty files, its primary technical purpose is to manage file timestamps. Every Linux file tracks three critical times: atime (access), mtime (modification), and ctime (change).

---

## Basic Usage

```bash
# Create a single empty file
touch filename.txt

# Create multiple files
touch file1.txt file2.txt file3.txt
```

---

## Common Flags

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-a` | | Change only the access time |
| `-m` | | Change only the modification time |
| `-c` | `--no-create` | Do not create any files |
| `-d` | `--date=STRING` | Parse STRING and use it instead of current time |
| `-t` | | Use `[[CC]YY]MMDDhhmm[.ss]` format |
| `-r` | `--reference=FILE` | Use this file's times instead of current time |
| `-h` | `--no-dereference` | Affect symbolic link instead of referenced file |

## Examples & Demos

### Creating Files

```bash
# Create a single empty file
$ touch newfile.txt

# Create multiple files
$ touch file1.txt file2.txt file3.txt

# Touch existing file (updates timestamp, doesn't erase content)
$ touch existing_file.txt
```

### Brace Expansion (Batch Creation)

```bash
# Create sequential numbered files
$ touch file{1..10}.txt
# Creates: file1.txt, file2.txt, ... file10.txt

# Create with zero-padding
$ touch file{01..10}.txt
# Creates: file01.txt, file02.txt, ... file10.txt

# Create lettered sequence
$ touch data_{A..E}.csv
# Creates: data_A.csv, data_B.csv, data_C.csv, data_D.csv, data_E.csv

# Create files with pattern
$ touch test_{01..05}_report.md
# Creates: test_01_report.md, test_02_report.md, etc.

# Combine patterns
$ touch {jan,feb,mar}_2026_{income,expenses}.csv
# Creates 6 files: jan_2026_income.csv, jan_2026_expenses.csv, etc.

# Multiple extensions
$ touch readme.{txt,md,rst}
# Creates: readme.txt, readme.md, readme.rst
```

### Modifying Timestamps

```bash
# Update both access and modification time to now
$ touch filename.txt

# Update only access time
$ touch -a filename.txt

# Update only modification time
$ touch -m filename.txt

# Don't create file if it doesn't exist
$ touch -c maybe_exists.txt

# Combine: update mod time only, don't create
$ touch -cm filename.txt
```

### Copying Timestamps

```bash
# Copy timestamp from another file
$ touch -r reference_file.txt target_file.txt

# Copy timestamps to multiple files
$ touch -r template.txt file1.txt file2.txt file3.txt
```

### Setting Specific Dates

```bash
# Set specific date and time
$ touch -d "2025-12-25 10:00:00" christmas_file.txt

# Just date (time defaults to 00:00:00)
$ touch -d "2025-12-25" holiday.txt

# ISO 8601 format
$ touch -d "2025-12-25T10:00:00" file.txt
```

### Relative Time

```bash
# Set to 2 days ago
$ touch -d "2 days ago" old_file.txt

# Set to yesterday
$ touch -d "yesterday" another_file.txt

# Set to next Monday
$ touch -d "next monday" future_file.txt

# Set to last week
$ touch -d "last week" archived.txt

# Set to 1 hour ago
$ touch -d "1 hour ago" recent.txt

# Set to tomorrow noon
$ touch -d "tomorrow 12:00" scheduled.txt
```

### Timestamp Format (-t)

Format: `[[CC]YY]MMDDhhmm[.ss]`

```bash
# Set to December 25, 2025, 10:00:00 AM
$ touch -t 202512251000.00 xmas.txt

# Set to March 15, 2026, 3:30 PM
$ touch -t 202603151530 meeting.txt

# Current year, June 1st, midnight
$ touch -t 06010000 summer_start.txt

# With seconds
$ touch -t 202601011200.30 file.txt
```

### Symbolic Links

```bash
# By default, touch affects the target of a symlink
$ touch link_to_file

# To affect the symlink itself, use -h
$ touch -h symbolic_link
```

## Verify Timestamps

```bash
# View all timestamps with stat
$ stat filename.txt
  File: filename.txt
  Size: 0         	Blocks: 0          IO Block: 4096   regular empty file
Access: 2026-02-14 10:30:00.000000000 -0500
Modify: 2026-02-14 10:30:00.000000000 -0500
Change: 2026-02-14 10:30:00.000000000 -0500

# View modification time with ls
$ ls -l filename.txt
-rw-r--r-- 1 user user 0 Feb 14 10:30 filename.txt

# View access time
$ ls -lu filename.txt

# View change time
$ ls -lc filename.txt
```

---

## Timestamp Types Explained

| Timestamp | Name | Changed When |
|-----------|------|--------------|
| atime | Access Time | File content is read |
| mtime | Modification Time | File content is modified |
| ctime | Change Time | File metadata (permissions, owner) changes |

## Practical Use Cases

### Create Project Structure

```bash
# Create multiple config files at once
$ touch .gitignore .env .editorconfig .prettierrc

# Create placeholder files
$ touch src/{index,app,utils,config}.js
```

### File Aging for Testing

```bash
# Create files with different ages for testing backup scripts
$ touch -d "30 days ago" old_backup.tar.gz
$ touch -d "7 days ago" weekly_backup.tar.gz
$ touch -d "yesterday" daily_backup.tar.gz
```

### Prevent Accidental Modification

```bash
# Create trigger file for scripts
$ touch .last_run

# Check age in scripts
if [ "$(find .last_run -mmin +60)" ]; then
    echo "More than an hour since last run"
fi
```

---

> **Pro Tip:** Unlike other commands, if you `touch` an existing file, it will NOT erase the contents—it only updates timestamps.
