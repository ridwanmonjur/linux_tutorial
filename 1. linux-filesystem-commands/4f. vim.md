# vim - Vi Improved Text Editor

Vim is a powerful, modal text editor based on the classic Unix `vi` editor. Unlike nano, vim operates in different modes: Normal, Insert, Visual, and Command-line mode. This modal approach enables efficient text editing once mastered.

---

## Understanding Vim Modes

| Mode | Purpose | How to Enter |
|------|---------|--------------|
| Normal | Navigate and manipulate text | Press `Esc` from any mode |
| Insert | Type and edit text | Press `i`, `a`, `o`, etc. |
| Visual | Select text | Press `v`, `V`, or `Ctrl+v` |
| Command-line | Execute commands | Press `:` from Normal mode |

---

## Basic Usage

```bash
# Open or create a file
vim filename.txt

# Open file at specific line
vim +50 largefile.txt

# Open file in read-only mode
vim -R file.txt
# or
view file.txt

# Open multiple files
vim file1.txt file2.txt

# Open files in split windows
vim -o file1.txt file2.txt    # horizontal split
vim -O file1.txt file2.txt    # vertical split
```

## Command-line Mode (`:` commands)

### File Operations

| Command | Action |
|---------|--------|
| `:w` | Save file |
| `:w filename` | Save as filename |
| `:q` | Quit |
| `:q!` | Quit without saving |
| `:wq` or `:x` or `ZZ` | Save and quit |
| `:e filename` | Edit another file |
| `:r filename` | Insert file contents |

### Search and Replace

| Command | Action |
|---------|--------|
| `/pattern` | Search forward |
| `?pattern` | Search backward |
| `n` | Next match |
| `N` | Previous match |
| `*` | Search word under cursor forward |
| `#` | Search word under cursor backward |
| `:%s/old/new/g` | Replace all in file |
| `:%s/old/new/gc` | Replace all with confirmation |
| `:s/old/new/g` | Replace all in current line |

### Window Management

| Command | Action |
|---------|--------|
| `:split` or `:sp` | Horizontal split |
| `:vsplit` or `:vs` | Vertical split |
| `Ctrl+w w` | Switch between windows |
| `Ctrl+w h/j/k/l` | Navigate windows |
| `Ctrl+w q` | Close window |
| `:only` | Close all other windows |

### Tabs

| Command | Action |
|---------|--------|
| `:tabnew` | New tab |
| `:tabnew file` | Open file in new tab |
| `gt` | Next tab |
| `gT` | Previous tab |
| `:tabclose` | Close tab |

### Other Useful Commands

| Command | Action |
|---------|--------|
| `:set number` | Show line numbers |
| `:set nonumber` | Hide line numbers |
| `:set relativenumber` | Show relative line numbers |
| `:set paste` | Enable paste mode |
| `:set nopaste` | Disable paste mode |
| `:syntax on` | Enable syntax highlighting |
| `:noh` | Clear search highlighting |
| `:!command` | Execute shell command |
| `:r !command` | Insert command output |

## Command Line Flags

| Flag | Description |
|------|-------------|
| `-R` | Read-only mode |

## Examples & Demos

### Basic Editing Session

```bash
$ vim notes.txt
# Press i to enter Insert mode
# Type your text
# Press Esc to return to Normal mode
# Type :wq to save and quit
```

### Quick Edits

```bash
# Open and go to line 100
$ vim +100 config.ini

# Open and search for "error"
$ vim +/error logfile.txt

# Open in diff mode
$ vim -d file1.txt file2.txt
```

### Using Vim for Quick Tasks

```bash
# Edit and run a command
$ vim -c ":%s/old/new/g" -c ":wq" file.txt

# View file read-only
$ vim -R important.conf
# or
$ view important.conf
```

## Configuration (~/.vimrc)

Create or edit `~/.vimrc` to set permanent preferences:

```vim
" Enable syntax highlighting
syntax on

" Show line numbers
set number

" Enable relative line numbers
set relativenumber

" Set tab width
set tabstop=4
set shiftwidth=4
set expandtab

" Enable auto-indent
set autoindent
set smartindent

" Highlight search results
set hlsearch
set incsearch

" Show matching brackets
set showmatch

" Enable mouse support
set mouse=a

" Show cursor position
set ruler

" Enable file type detection
filetype plugin indent on

" Set color scheme
colorscheme desert

" Show status line
set laststatus=2

" Enable clipboard integration
set clipboard=unnamedplus

" Disable swap files
set noswapfile

" Enable line wrapping
set wrap
set linebreak
```

| Visual mode | No | Yes |
| Split windows | No | Yes |

## Tips for Beginners

1. **Start with vimtutor**: Run `vimtutor` in terminal for an interactive tutorial
2. **Remember Esc**: Always press `Esc` when unsure - it returns you to Normal mode
3. **Don't panic**: `:q!` quits without saving if you get stuck
4. **Use hjkl**: Practice using hjkl instead of arrow keys
5. **Think in verbs and nouns**: `d` (delete) + `w` (word) = delete word
